# LICHOMAT v0.3: performance and acid — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v0.3 of LICHOMAT as accepted in §6 and §7 of `docs/superpowers/specs/2026-10-29-stage2-draft.md` (written there as "v0.4"; it ships as v0.3 since 2026-10-30): a held fill mode, 8 mute scenes per project applied at the bar or the step, extra roll rates (1/3, 1/6, 1/12, 1/24, 1/32) that follow each track's own step, a per-step slide for Drum 1–3 with a per-voice slide time, the version bump, the owner's checks and release notes, and demo renders.

**Architecture:** The performance features live in the performance mode (the second mode button), where the voices already mute and steps 1–7 already roll: step 8 held is fill, steps 9–16 recall scenes, COPY + steps 9–16 store them. `seq_core` gets a roll code (span in steps, hits) with exact integer hit positions at every tempo, a slide event flag and a masked probability byte; the scenes are applied by the sequencer at the master boundary and saved after the project name in `prj.nfo`; the slide is a per-block pitch factor in the Drum voice, its flag bit 7 of `Step.prob`, its time a kit parameter that fw 1.7 never used.

**Tech Stack:** C11 (firmware: Arm GNU 14.3, `-ffast-math`; host tests: Apple clang 17, UBSan, a strict-FP copy of the core), CMake 3.31, Ninja, ctest, Python 3 (the emulator's `render_test.py`), bash.

| D16 | **Fill is step 8 held in the performance mode** (MODE2 without SHIFT). One finger, next to the rolls. The CC map has no clean slot: `midiParser_cc2voiceNr()` gives every CC 1–127 a voice and `midiParser_ccHandler()` a sound parameter (F13). |
| D17 | **Mute scenes: in the performance mode step 9–16 recalls scene 1–8, COPY + step 9–16 stores the current mutes as scene 1–8.** A scene holds bit 7 "stored" and the muted tracks in bits 0–6. The latest recall wins; the recalled scene's step LED blinks until it applies. | The suggested SHIFT + step collides: SHIFT + steps 10 and 12–16 open song, config, reload, last step, FX and pattern (F12). Each hit gets its step's swing (as ratchets); `ev.hit` is j. | Exact integer arithmetic at every tempo of D7, also for triplets at ×3/4, ×3/2, ×3 (L = 128, 64, 32, where 2L/3 is not whole). Anchored on the track's step index as v0.1's `step % rate`. |
| D23 | **The slide flag is bit 7 of `Step.prob`, not of `Step.note`.** `prob & 0x7F` is the probability (0–100) or the trig condition (101–115; 116–127 play like 100). | fw 1.7 does not ignore note bit 7 (F10): `osc_setBaseNote()` adds `baseNote − 63` to the coarse tune and clamps at 127, so a flagged note plays at the top pitch, and `seq_sendMidiNoteOn()` sends the byte unmasked as MIDI data. fw 1.7 plays every probability above 100 like 100 (v0.2 F1) and v0.2 plays 116–255 like 100 (v0.2 D11): there a slide step plays as at 100 % (a slide step with a probability or a condition loses it in fw 1.7 and v0.2), pitch and MIDI stay correct. | D24 | **Slide:** a step with the flag on Drum 1–3 triggers as usual (envelopes restart); the pitch of its oscillator and modulator starts at the voice's previous note (plus any glide still in progress) and moves linearly in semitones to the new note over the slide time, per 64-sample audio block. Linear in semitones is the usual portamento curve; per block is how the Drum voice already updates its pitch (F19). |

- **F10** fw 1.7 (`main`) passes `Step.note` unmasked: `seq_triggerVoice()` → `voiceControl_noteOn(voiceNr, note, vol)` → `Drum_trigger()` → `osc_setBaseNote()`: `note = (midiFreq>>8) + (baseNote − SEQ_DEFAULT_NOTE)`, clamped to 0–127; and `seq_sendMidiNoteOn()` sets `msg.data1 = note`. The only bit-7 use of the note (`PATTERN_END 0x80`) is commented out. So note bit 7 is not ignored.

Register after `test_conditions`: `seqc_add_test(test_perform IDS RL1 RL2 STRICT_CORE seq_core_strict)    # v0.3 P1 rolls, P2 slide`.

```c
#include "fake_host.h"
#include "seqc_test.h"

static const fake_rec_t *trig[64];

/* start at time 0 and run for ms at the fake host's 120 BPM (96 ticks = 125 ms) */
static void play(fake_host_t *h, double ms)
{
	fake_process(h, 0);
	seqc_start();
	fake_process(h, 0);
	fake_runUntil(h, fake_msToCycles(ms), fake_msToCycles(0.1));
}

TEST(RL1_sub_step_and_triplet_rolls_at_x1)
{
	/* track 3 at x1, no steps: the roll hits of ticks 0..767 (8 steps) */
	static const struct { uint8_t rate; uint8_t hits; size_t n; uint16_t gap; } cases[] = {
		{ SEQC_ROLL(1, 2), 2, 16, 48 },		/* 1/32 */
		{ SEQC_ROLL(2, 3), 3, 12, 64 },		/* 1/24 */
		{ SEQC_ROLL(4, 3), 3, 6, 128 },		/* 1/12 */
		{ SEQC_ROLL(8, 3), 3, 3, 256 },		/* 1/6 */
		{ SEQC_ROLL(16, 3), 3, 2, 512 },	/* 1/3: 0 and 512 of 0, 512, 1024 */
	};
	for (size_t i = 0; i < sizeof cases / sizeof cases[0]; i++)
	{
		fake_host_t *h = fake_init();
		h->rollRate[3] = cases[i].rate;
		play(h, 8 * 125.0 - 1.0);
		const size_t n = fake_triggers(h, 3, trig, 64);
		ASSERT_EQ(n, cases[i].n);
		for (size_t k = 0; k < n; k++)
		{
			const seqc_event_t *ev = &trig[k]->ev;
			ASSERT_EQ(ev->tick, (int64_t)(k * cases[i].gap));
			ASSERT_EQ(ev->step, (uint8_t)(k * cases[i].gap / 96));
			ASSERT_EQ(ev->hit, (uint8_t)(k % cases[i].hits));
			ASSERT_EQ(ev->flags, SEQC_EVF_ROLL);
			ASSERT_EQ(ev->vel, SEQC_ROLL_VELOCITY);
		}
		ASSERT_EQ(h->errors, 0);
	}
}

TEST(RL1_old_rates_are_span_with_one_hit)
{
	ASSERT_EQ(SEQC_ROLL(16, 1), 16);
	ASSERT_EQ(SEQC_ROLL(8, 1), 8);
	ASSERT_EQ(SEQC_ROLL(1, 1), 1);
	ASSERT_EQ(SEQC_ROLL_SPAN(SEQC_ROLL(16, 3)), 16);
	ASSERT_EQ(SEQC_ROLL_HITS(SEQC_ROLL(1, 2)), 2);
	ASSERT_TRUE(SEQC_ROLL(16, 8) != 0xFF);	/* never the one-shot code of sequencer.c */
}

TEST(RL2_triplet_roll_at_x3_4_is_exact)
{
	/* x3/4: L = 128 ticks; 1/12 = 3 hits every 4 steps (512 ticks) at floor(j * 512 / 3) */
	fake_host_t *h = fake_init();
```

```c
#define SLIDE_H_
/* LICHOMAT v0.3: the slide (glide) of Drum 1-3 (plan D24, D25): a pitch factor per audio block
 * that starts at the previous note and reaches 1 (the new note) linearly in semitones */
#include <math.h>
#include <stdint.h>

#define SLIDE_RATE		44100u	/* the audio sample rate */
#define SLIDE_BLOCK		64u	/* samples per control block: OUTPUT_DMA_SIZE (config.h) */
#define SLIDE_MS_PER_VALUE	4u	/* PAR_SLIDE_TIMEx 0..127 -> 0..508 ms */

typedef struct
{
	float		semis;	/* the offset of the next block from the new note */
	float		step;	/* semitones per block */
	uint16_t	left;	/* blocks to go; 0 = no glide */
} slide_t;

/** the blocks of a slide time value, rounded */
static inline uint16_t slide_blocks(uint8_t value)
{
	const uint32_t samples = (uint32_t)value * SLIDE_MS_PER_VALUE * SLIDE_RATE / 1000u;
	return (uint16_t)((samples + SLIDE_BLOCK / 2u) / SLIDE_BLOCK);
}

static inline void slide_stop(slide_t *s)
{
	s->semis = 0.0f;
	s->step = 0.0f;
	s->left = 0;
}

/** the offset in semitones of the glide in progress, 0 without one */
static inline float slide_offset(const slide_t *s)
{
	return s->left ? s->semis : 0.0f;
}

/** a glide from semis (the previous pitch minus the new note) to 0 over blocks */
static inline void slide_start(slide_t *s, float semis, uint16_t blocks)
{
	if (blocks == 0 || fabsf(semis) < 1e-6f)
	{
		slide_stop(s);
		return;
	}
	s->semis = semis;
	s->step = semis / (float)blocks;
	s->left = blocks;
}

/** the pitch factor of the next block */
static inline float slide_next(slide_t *s)
{
	if (s->left == 0)
		return 1.0f;
	const float f = exp2f(s->semis * (1.0f / 12.0f));
	s->semis -= s->step;
	if (--s->left == 0)
		s->semis = 0.0f;
	return f;
}
```

```python
def wav_left(path):
    """(rate, the left channel as floats) of a PCM 16/24-bit or float 32-bit WAV"""
    import struct
    with open(path, 'rb') as f:
        b = f.read()
    pos, fmt, data = 12, None, b''
    while pos + 8 <= len(b):
        cid, size = b[pos:pos + 4], struct.unpack_from('<I', b, pos + 4)[0]
        if cid == b'fmt ':
            tag, ch, rate, _, _, bits = struct.unpack_from('<HHIIHH', b, pos + 8)
            fmt = (tag, ch, rate, bits)
        elif cid == b'data':
            data = b[pos + 8:pos + 8 + size]
        pos += 8 + size + (size & 1)
    tag, ch, rate, bits = fmt
    step = ch * bits // 8
    idx = range(0, len(data) - step + 1, step)
    if tag == 3 and bits == 32:
        return rate, [struct.unpack_from('<f', data, i)[0] for i in idx]
    if bits == 16:
        return rate, [struct.unpack_from('<h', data, i)[0] / 32768 for i in idx]
    if bits == 24:
        return rate, [int.from_bytes(data[i:i + 3], 'little', signed=True) / 8388608 for i in idx]
    raise ValueError('WAV format %r' % (fmt,))
```
