# LICHOMAT v0.5: sample-accurate voice triggering (E6.10) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v0.5 of LICHOMAT as specified in `docs/superpowers/specs/2026-10-31-sample-accurate-triggering.md` (commit `6405443`, decisions S1–S22, accepted under the owner's delegation): every voice starts at the sample of its event, a constant 128 frames (2.90 ms) after it, with the setting `trg` `smp`/`blk` (`blk` is v0.4's path), the emulator's trigger log and onset tool, the goldens G16–G19, five `_blk` goldens that prove `blk` is v0.4 bit for bit, one re-bless of the 23 goldens, and the owner's checks U27–U32.

**Architecture:** A new plain-C11 module `vsched` (host-tested like `seq_core`) holds a ring of 4 trigger records per voice, the block window stamped at each SPI3 DMA completion (late-only filter, two slots under a serial), the offset arithmetic (2-sample grid, the late rule), the collapse, the cap and the per-voice phase. The trigger glue keeps MIDI, LEDs, recording and the slide bookkeeping at fire time and posts the voice side (p-locks, slide mode, trigger) as a record with `seqc_itemTime()` or the MIDI arrival stamp. The mixer applies offset-0 records before its control path, renders a voice with a record in two parts around its offset (a control step at the split, the pan latch per segment), finishes the new note's first control step in the next block (the phase split), and mixes through one per-voice helper; with no records it computes exactly what v0.4 computed.

**Tech Stack:** C11 (firmware: Arm GNU 14.3, `-O3 -ffast-math -mfp16-format=ieee`; host tests: Apple clang 17, UBSan), CMake 3.31, Ninja, ctest, Python 3 (`render_test.py`, `emu_golden.py`, `emu_onsets.py`, `emu_fuzz.py`), bash.

The stage 1 spec and implementation notes, the emulator spec and the plans of v0.2–v0.4 (D1–D44, with v0.4's "Corrections after A1–A6") still hold. ## Decisions taken while planning

| # | Decision | Why |
|---|---|---|
| P1 | **No `audio_blockDone()` in ITCM.** The SPI3 branch of `HAL_I2S_TxCpltCallback()` and the emulator's `emu_blockBody()` call `vsched_blockDone(DWT->CYCCNT)`, the spec §5.2 filter, in `vsched.c` (flash). | The filter stays in the host-tested, HAL-free module; one call per 1.45 ms; `tests/test_dmabuf.c` includes `AudioCodecManager.c` itself and would need `vsched` linked; ITCM stays for the mixer. |
| P2 | **The window read** loads the serial, the slot, then the serial again; if two completions came between, it reads once more (no spin). A window not 0.5–2 blocks long (the first completion, a re-seed after a stall) is no window: every record goes to offset 0, timed ones count as late. | The main loop's read can be preempted by TIM14, USART3, OTG_FS and EXTI for longer than §5.2 assumes; one bounded retry costs nothing. |
| P3 | **A voice's due records collapse at the largest offset among them** and are applied in posting order. | Records of one voice can be posted out of time order (a MIDI note after a sequencer event in one `seq_tick()`); §9.1 asks that k = 0 and k = 40 both go to 40. |
| P4 | **Each ring is an array of 4, oldest first, with due and late bit masks**; the due records are taken out wherever they are. | A waiting record can precede a due one (P3). |
| P5 | **The drum gain ramp is indexed by the step's sample**, 0–63 across the step's parts (`bufferTool_addGainRamp()`, fw 1.7's arithmetic; past 63 it holds the target). A step cut short (the old note at a split, the step after a phase split at the block end) ends at the gain of its last rendered sample, which the next step ramps from. | fw 1.7 ramps i/63 (`i/(size-1)`), not "n/64 of the way" (§4.2): indexing reproduces v0.4 bit for bit for whole blocks (the prototype's hash of 1,200 drum blocks matched v0.4's in strict and fast FP), and a split block equals an unsplit one exactly. |
| P6 | **`voices.h`** (header-only, inlined into the ITCM mixer) dispatches by voice number: filter, control step, render, pan latch, LFO re-dispatch. The six mixer sections become `mixer_voice()`; `mixer_addDataToOutput()` becomes `mixer_addSegment()` in `mixerOut.h`, its jack check made once per voice. | One code path for whole blocks and splits, testable on the host. /** spec 5.3: the fate of a record of time t in the window [w0, w0 + len), and its offset
 * k in {0, 2, ..., 62} when due; modulo 2^32 */
static inline vsched_fate_t vsched_offset(uint32_t t, uint32_t w0, uint32_t len, uint8_t *k)
{
	const int32_t d = (int32_t)(t - w0);
	*k = 0;
	if (d < -(int32_t)(len / 32u))
		return VS_LATE;
	if (d < 0)
		return VS_DUE;		/* rounded into this block by the one before: offset 0, not counted */
	if ((uint32_t)d >= len)
		return VS_WAIT;
	const uint32_t j = (32u * (uint32_t)d + len / 2u) / len;	/* below 2^25 */
	if (j >= 32u)
		return VS_WAIT;		/* the next block gives it -L/32 <= d < 0 */
	*k = (uint8_t)(2u * j);
	return VS_DUE;
}

/** S9: a MIDI arrival time from its 16-bit stamp (DWT >> 8) and the time now; at most
 * 255 cycles early; a stamp older than 77.7 ms reads as younger, never later than now */
static inline uint32_t vsched_stampTime(uint32_t now, uint16_t s16)
{
	const uint16_t age = (uint16_t)((uint16_t)(now >> 8) - s16);
	return (now & ~0xFFu) - ((uint32_t)age << 8);
}

 * read again shows a second one, and the read is made once more (no spin). Not 0.5-2
 * blocks long (the first completion, a re-seed): no window */
static int vs_window(uint32_t *w0, uint32_t *len, uint32_t *serial)
{
	for (int attempt = 0; attempt < 2; attempt++)
	{
		const uint32_t s = vs_serial;
		VS_READ_HOOK(0);
		const uint32_t a = vs_slot[s & 1u].w0;
		VS_READ_HOOK(1);
		const uint32_t b = vs_slot[s & 1u].w1;
		VS_READ_HOOK(2);
		if (vs_serial - s < 2u)
		{
			*w0 = a;
			*len = b - a;
			*serial = s;
			return s != 0u && *len >= VSCHED_BLOCK_CYCLES / 2u && *len <= 2u * VSCHED_BLOCK_CYCLES;
		}
	}
	return 0;
}
//------------------------------------------------------------------------------
void vsched_post(const vsched_rec_t *r)
{
	if (!seq_isInTick())
	{
		vs_stats.offTick++;				/* S17, P9 */
		return;
	}
	const uint8_t v = vsched_voiceOf(r->track);
	if (vs_count[v] == VSCHED_RING)
	{
		memmove(&vs_rec[v][0], &vs_rec[v][1], (VSCHED_RING - 1u) * sizeof vs_rec[v][0]);
		vs_count[v]--;
		vs_stats.overflow++;
	}
	vs_rec[v][vs_count[v]++] = *r;
}
//------------------------------------------------------------------------------
void vsched_beginBlock(void)
{
	uint32_t w0 = 0, len = 0, serial = 0;
	const int haveWindow = vs_window(&w0, &len, &serial);
	vs_planSerial = serial;
	uint8_t splitting = 0;
	for (uint8_t v = 0; v < VSCHED_VOICES; v++)
	{
		vs_due[v] = vs_late[v] = vs_k[v] = 0;
		for (uint8_t i = 0; i < vs_count[v]; i++)
		{
			const vsched_rec_t *r = &vs_rec[v][i];
			uint8_t k = 0;
			/* untimed (S10): offset 0; no window: offset 0, counted late */
			const vsched_fate_t f = !(r->flags & VS_TIMED) ? VS_DUE
				: !haveWindow ? VS_LATE : vsched_offset(r->time, w0, len, &k);
			if (f == VS_WAIT)
				continue;
			vs_due[v] |= (uint8_t)(1u << i);
			if (f == VS_LATE)
				vs_late[v] |= (uint8_t)(1u << i);
			if (k > vs_k[v])
				vs_k[v] = k;			/* S2: all at the last offset (P3) */
		}
		if (vs_k[v] || vs_phase[v])
			splitting++;
	}
	if (splitting > VSCHED_SPLIT_CAP)
	{
		memset(vs_k, 0, sizeof vs_k);		/* S20: the block falls back to block timing */
		memset(vs_phase, 0, sizeof vs_phase);
		vs_stats.capFallbacks++;
	}
}
//------------------------------------------------------------------------------
/** apply voice v's due records in order (p-locks, slide mode, trigger), then drop them */
static void vs_apply(uint8_t v, uint8_t k)
{
	uint8_t kept = 0;
	for (uint8_t i = 0; i < vs_count[v]; i++)
	{
		const vsched_rec_t r = vs_rec[v][i];
		if (!(vs_due[v] & (1u << i)))
		{
			vs_rec[v][kept++] = r;
			continue;
		}
		const uint8_t late = (uint8_t)((vs_late[v] >> i) & 1u);
		if (late)
			vs_stats.late++;
		if (r.flags & VS_PLOCKS)
			seq_applyPlocks(r.track, r.p1Nr, r.p1Val, r.p2Nr, r.p2Val);
		if (r.track < 3u)
			Drum_setSlide(r.track, (uint8_t)((r.flags & VS_SLIDE_MASK) >> VS_SLIDE_SHIFT));
		voiceControl_trigger(r.track, r.note, r.vel);
		if (vs_trace)
			vs_trace(&r, vs_planSerial, k, late);
	}
	vs_count[v] = kept;
	vs_due[v] = vs_late[v] = 0;
}
//------------------------------------------------------------------------------
void vsched_applyPhase0(void)
{
	for (uint8_t v = 0; v < VSCHED_VOICES; v++)
		if (vs_due[v] && vs_k[v] == 0)
		{
			vs_apply(v, 0);
			vs_phase[v] = 0;	/* a new note at offset 0: its control step is the block's */
		}
}
//------------------------------------------------------------------------------
uint8_t vsched_split(uint8_t v)
{
	return v < VSCHED_VOICES ? vs_k[v] : 0;
}
//------------------------------------------------------------------------------
uint8_t vsched_phase(uint8_t v)
{
	return v < VSCHED_VOICES ? vs_phase[v] : 0;
}
//------------------------------------------------------------------------------
void vsched_applySplit(uint8_t v)
{
	if (v >= VSCHED_VOICES || vs_k[v] == 0)
		return;
	vs_apply(v, vs_k[v]);
	vs_phase[v] = vs_k[v];
	vs_k[v] = 0;
	vs_stats.splits++;
}
//------------------------------------------------------------------------------
void vsched_endPhase(uint8_t v)
{
	if (v < VSCHED_VOICES && vs_phase[v])
	{
		vs_phase[v] = 0;
		vs_stats.phaseSplits++;
	}
}

{
	*out = vs_stats;
}

static void setSound(const sound_t *s)

/** one block of voice v as the mixer runs it: the block's control step (unless a
 * phase phi is pending), then the render, split at k (with a trigger) or at phi */
static uint8_t block(uint8_t v, int16_t *out, uint8_t phi, uint8_t k, int trig)
{
	if (!phi)
		voices_control(v);
	if (k)
	{
		voices_render(v, out, k);
		if (trig)
			trigger(v);
		voices_control(v);
		voices_render(v, out + k, (uint8_t)(BLOCK - k));
		return k;
	}
	if (phi)
	{
		voices_render(v, out, phi);
		voices_control(v);
		voices_render(v, out + phi, (uint8_t)(BLOCK - phi));
		return 0;
	}
	voices_render(v, out, BLOCK);
	return 0;
}

}

static int maxDiff(const int16_t *a, const int16_t *b, int n)
{
	int m = 0;
	for (int i = 0; i < n; i++)
	{
		const int d = a[i] > b[i] ? a[i] - b[i] : b[i] - a[i];
		if (d > m)
			m = d;
	}
	return m;
}

/** a note: the smoothers settled, a trigger at offset 0; its first block (the test
 * block, loudest: its amp EG falls fast) is played whole (k 0) or as [0, k) + [k, 64)
 * with no trigger at k, then one block more */
static void ringing(uint8_t v, uint8_t k, int16_t *out, uint8_t *state, uint32_t *rngAfter)
{
	static const sound_t s = { 0, 1, 1 };
	__attribute__((aligned(4))) int16_t buf[BLOCK];
	setSound(&s);
	for (int b = 0; b < 200; b++)
		block(v, buf, 0, 0, 0);
	trigger(v);
	voices_control(v);
	if (k)
	{
		voices_render(v, out, k);
		voices_render(v, out + k, (uint8_t)(BLOCK - k));
	}
	else
		voices_render(v, out, BLOCK);
	block(v, out + BLOCK, 0, 0, 0);
	size_t n;
	memcpy(state, stateOf(v, &n), n);
	*rngAfter = rng;
}

#!/usr/bin/env python3
"""The onset timing of a render (plan v0.5 Task 9, spec 9.2): where each hit of a
click starts in a channel of a lichomat-render WAV, against one of three references.

    emu_onsets.py WAV --log TRIG.LOG [--voice V] [options]   against the trigger log
    emu_onsets.py WAV --grid BPM [options]                     against the tick grid
    emu_onsets.py WAV --against WAV2 [options]                 against another render

An onset is the first frame with |x| >= 4,000 after at least 32 frames below 64.
- --log: the timed records of voice V (0-5, default 0) of lichomat-render's
  --trig-log, the last of each block serial (a voice's records in one block start
  together, S2; the one-shot roll's records are untimed and left out);
  each is expected at frames(t) + 128, t its event time in cycles from t0, frames()
  at 44,140.625 Hz. Each record is matched with the onset nearest to it within 96
  frames; a record or an onset without a match is an error.
- --grid BPM: the onsets on a grid of ticks (384 a quarter note) at BPM, from the
  first onset: each one's tick is the nearest. It does not read the firmware's times.
- --against WAV2: the onsets of WAV2 in the same channel, one for one.
The residuals r = onset - reference; c is their median, and the spread is
max(r - c) - min(r - c). --from/--to (seconds) keep the onsets in [from, to).
Exit 0 if the spread is at most --limit and at least --min (each if given), 1 if not
or on an unmatched onset or record, 2 on a usage error.

SPDX-License-Identifier: GPL-3.0-only

Licensed under the GNU General Public License version 3, with the additional
permission and terms in NOTICE.md. See LICENSE and NOTICE.md in the root of
the repository.

import argparse
import array
import fractions
import json
import sys
import wave

RATE = fractions.Fraction(353125, 8)     # 44,140.625 Hz
CYCLES_PER_FRAME = fractions.Fraction(552960, 113)
LATENCY = 128                            # frames: two blocks (S4)
CHANNELS = ('L1', 'R1', 'L2', 'R2')
LOUD, QUIET, QUIET_FRAMES, MATCH = 4000, 64, 32, 96


class Usage(Exception):
    pass


def channel(path, name):
    with wave.open(path, 'rb') as w:
        if w.getsampwidth() != 2:
            raise Usage('%s: not a 16-bit WAV' % path)
        n, frames = w.getnchannels(), w.getnframes()
        data = array.array('h')
        data.frombytes(w.readframes(frames))
    if sys.byteorder == 'big':
        data.byteswap()
    c = CHANNELS.index(name)
    if c >= n:
        raise Usage('%s has %d channels, no %s' % (path, n, name))
    return data[c::n]


def onsets(x):
    out, quiet = [], 0
    for f, v in enumerate(x):
        a = -v if v < 0 else v
        if a >= LOUD and quiet >= QUIET_FRAMES:
            out.append(f)
            quiet = 0
        elif a < QUIET:
            quiet += 1
        else:
            quiet = 0
    return out


def records(path, voice):
    """(expected frame, line) of the voice's records, the last of each block serial"""
    last = {}
    order = []
    with open(path) as f:
        for n, line in enumerate(f, 1):
            w = line.split()
            if len(w) != 6:
                raise Usage('%s:%d: not "<cycles> <voice> <src> <serial> <k> <late>"' % (path, n))
            if int(w[1]) != voice or w[2] == 'oneshot':
                continue                 # another voice, or an untimed record (S10)
            serial = int(w[3])
            if serial not in last:
                order.append(serial)
            last[serial] = (float(fractions.Fraction(int(w[0])) / CYCLES_PER_FRAME) + LATENCY, n, int(w[5]))
    return [last[s] for s in order]


def median(v):
    s = sorted(v)
    m = len(s) // 2
    return s[m] if len(s) % 2 else (s[m - 1] + s[m]) / 2


def main(argv=None):
    ap = argparse.ArgumentParser(prog='emu_onsets.py', description=__doc__.split('\n\n')[0])
    ap.add_argument('wav')
    ap.add_argument('--channel', default='L1', choices=CHANNELS)
    ref = ap.add_mutually_exclusive_group(required=True)
    ref.add_argument('--log')
    ref.add_argument('--grid', type=float, metavar='BPM')
    ref.add_argument('--against', metavar='WAV2')
    ap.add_argument('--voice', type=int, default=0, choices=range(6))
    ap.add_argument('--from', dest='start', type=float, default=0.0, metavar='S')
    ap.add_argument('--to', dest='end', type=float, default=None, metavar='S')
    ap.add_argument('--skip-late', action='store_true', help='leave out the records flagged late')
    ap.add_argument('--limit', type=float)
    ap.add_argument('--min', type=float)
    ap.add_argument('--json', metavar='FILE')
    a = ap.parse_args(argv)
    try:
        f0 = a.start * float(RATE)
        f1 = a.end * float(RATE) if a.end is not None else float('inf')
        keep = lambda f: f0 <= f < f1
        on = [f for f in onsets(channel(a.wav, a.channel)) if keep(f)]
        if not on:
            raise Usage('%s: no onset in %s' % (a.wav, a.channel))
        bad = []
        if a.log is not None:
            recs = [r for r in records(a.log, a.voice) if keep(r[0]) and not (a.skip_late and r[2])]
            used, res = set(), []
            for e, line, _ in recs:
                best = min((o for o in on if o not in used), key=lambda o: abs(o - e), default=None)
                if best is None or abs(best - e) > MATCH:
                    bad.append('record of line %d (frame %.1f) has no onset' % (line, e))
                    continue
                used.add(best)
                res.append(best - e)
            bad += ['onset at frame %d has no record' % o for o in on if o not in used]
        elif a.grid is not None:
            fpt = float(RATE) * 60.0 / (a.grid * 384.0)
            base = on[0]
            res = [o - base - round((o - base) / fpt) * fpt for o in on]
        else:
            other = [f for f in onsets(channel(a.against, a.channel)) if keep(f)]
            if len(other) != len(on):
                raise Usage('%d onsets in %s, %d in %s' % (len(on), a.wav, len(other), a.against))
            res = [o - p for o, p in zip(on, other)]
        for x in bad:
            print(x)
        if not res:
            raise Usage('nothing to compare')
        c = median(res)
        dev = [r - c for r in res]
        spread = max(dev) - min(dev)
        print('onsets %d, c %.2f frames, spread %.2f frames (%.2f .. %.2f)' % (len(res), c, spread, min(dev), max(dev)))
        if a.json:
            with open(a.json, 'w') as fj:
                json.dump({'onsets': len(res), 'c': c, 'spread': spread, 'residuals': dev}, fj)
        ok = not bad and (a.limit is None or spread <= a.limit) and (a.min is None or spread >= a.min)
        return 0 if ok else 1
    except Usage as e:
        print('emu_onsets.py: %s' % e, file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
