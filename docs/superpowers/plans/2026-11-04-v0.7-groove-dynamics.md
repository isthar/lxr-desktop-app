# LICHOMAT v0.7: groove dynamics (E6.26, Q35) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v0.7 of LICHOMAT as drafted in `docs/superpowers/specs/2026-11-04-v0.7-draft.md` (tracker E6.26, defaults of Q35): a velocity template per track (`vtp`, `vdp` 0–200 %, the four templates measured on the reference album), four own templates per project captured from a track (`sav`, `us1`–`us4`, timing and velocity together), a clear page for a track's microtiming, pattern-file block 3 and the project file `USERTPL.LCH`, with all 38 goldens of v0.6 unchanged, three level goldens checked against the table outside the firmware, and the owner's checks U38–U41.

**Architecture:** The timing core gets an optional host callback `vtmpl()` (a `TrackTemplate`: id 0..8, depth) and an optional data pointer `userTemplates` (4 × 16 timing offsets and 16 dB offsets). Each step occurrence reads both templates at one position q, v0.6's M6 rule, and scales the step's volume once, for all its hits, before v0.2's humanize volume: `vel = clamp(rha(vol × 10^(dB × d / 2000)), 1, 127)` through two Q15 gain tables in flash (`seqc_velScale()`), so with the template off or the depth 0 the event is v0.6's bit for bit. Timing template ids 8..11 read the own templates' timing part through the same pointer. `PatternSet` holds `vtpl[64][7]`; the glue captures a track's steps 1–16 into a slot and clears a track's microtiming; block 3 follows block 2, or block 1 when there is no block 2; `USERTPL.LCH` lives in the project folder and in `/tmp`. The menu reaches the sequencer through direct calls, as in v0.6.

**Tech Stack:** C11 (firmware: Arm GNU 14.3, `-O3 -ffast-math -mfp16-format=ieee`; host tests: Apple clang 21 from the Command Line Tools 26.6, UBSan, ASan + UBSan; CI: GCC on Linux, strict C11), CMake 3.31, Ninja, ctest, Python 3 (`render_test.py`, `emu_golden.py`, `emu_onsets.py`, `emu_fuzz.py`), bash.

## Draft deviations

1. **CPU (draft §3, brief item 5): ≈ 0.44 %, not ≤ 0.3 %, by the static method** (V7-21). v0.6's method counts every new instruction once per `seqc_generate()` call that reaches it, for 14 calls in the worst block, times 1.5. The velocity alone (callback, checks, table read, the scale) is ≈ 58 cycles a call, already 0.39 %. The executed path is shorter, and the mean is ≈ 0.006 %. D41's bound becomes 91.1 + 0.44 ≈ 91.5, below U20's 95. **U41's limit is 0.5 points**; Task 3's recount decides the number, and above 0.5 % is a finding.
2. **Loudness needs the voice's `vol` switch** (draft §2.1 assumes every hit gets louder or softer). The init card's hat has it off (F5); V7-19.
3. **The 200 % golden cannot match the table within ±0.5 dB**: integer velocities put step 10 (−32 dB) at velocity 3, −32.54 dB. It matches the formula's integer velocity (V7-18). At 50 and 100 % it matches the table itself.
4. **A volume of 0 stays 0** (the brief: "clamped to 1..127"), V7-4.
5. **RAM: +1,042 B, not +1,038**: `activeParameters` grows from 311 to 314 B and its alignment adds 4 B (V7-15).
6. **One existing emulator case and one existing host-test line change by design**: `V06_ui`'s three expectations of the track page (V7-16) and `test_presets.c:1624`'s invalid template id 8 → 12 (V7-1). All 38 goldens, `M17_seed_card` and every other test stay.
7. **Block 3 is written when any of its 14 data bytes is not 0** (a depth without a template counts), the brief's "some track has a velocity template" made exact (V7-13).
8. **The draft's "0.6 reads block 2 and closes the file"** holds for a file with block 2. For a file with block 1 and block 3 only, v0.6 reads block 3's header, rejects it and keeps its defaults (F8); same result.

TEST(vel_scale_matches_the_formula)
{
	/* every velocity 0..127, dB -45..+2 and depth 0..200 %: the formula rounded, except within
	 * 0.005 of a rounding tie, where either neighbour is right (planning: 565 such inputs, the
	 * farthest 0.0029 from the tie, and no other difference) */
	int ties = 0;
	for (int vel = 0; vel < 128; vel++)
		for (int db = -45; db <= 2; db++)
			for (int pct = 0; pct <= 200; pct++)
			{
				const int got = seqc_velScale((uint8_t)vel, db, (uint8_t)pct);
				if (vel == 0 || db >= 0 || pct == 0)
				{
					ASSERT_EQ(got, vel);
					continue;
				}
				const double x = velExact(vel, db, pct);
				if (got != velRound(x))
				{
					ASSERT_TRUE(fabs(x - floor(x) - 0.5) < 0.005);
					ASSERT_TRUE(got == velRound(floor(x)) || got == velRound(ceil(x)));
					ties++;
				}
			}
	printf("vel_scale: %d inputs within 0.005 of a tie round the other way\n", ties);
	ASSERT_TRUE(ties <= 600);
	ASSERT_EQ(seqc_velScale(100, -10, 201), seqc_velScale(100, -10, 200));	/* above 200 % as 200 */
	ASSERT_EQ(seqc_velScale(100, -10, 255), seqc_velScale(100, -10, 200));
	ASSERT_EQ(seqc_velScale(127, -60, 100), seqc_velScale(127, -42, 100));	/* below -42 dB as -42 */
	/* the draft's of8 at 100 % from 127, and the edges */
	static const uint8_t of8[16] = { 40, 23, 127, 25, 40, 25, 127, 28, 40, 20, 127, 25, 40, 23, 127, 28 };
	for (int q = 0; q < 16; q++)
		ASSERT_EQ(seqc_velScale(127, vtab[OF8][q], 100), of8[q]);
	ASSERT_EQ(seqc_velScale(127, -16, 200), 3);	/* -32 dB: 3.19 */
	ASSERT_EQ(seqc_velScale(1, -42, 200), 1);	/* never below 1 */
	ASSERT_EQ(seqc_velScale(0, -42, 200), 0);	/* a silent step stays silent */
	ASSERT_EQ(seqc_velScale(120, -14, 100), 24);
}

TEST(vel_scale_db_of_two_velocities)
{
	/* seqc_velDb(): -20 log10(vel / loudest) rounded to whole dB, -42..0; 0 for vel >= loudest or
	 * loudest 0, -42 for vel 0; a near-tie (within 0.005) may round to the neighbour (planning: 2) */
	int ties = 0;
	for (int loudest = 0; loudest < 128; loudest++)
		for (int vel = 0; vel < 128; vel++)
		{
			const int got = seqc_velDb((uint8_t)vel, (uint8_t)loudest);
			if (loudest == 0 || vel >= loudest)
			{
				ASSERT_EQ(got, 0);
				continue;
			}
			if (vel == 0)
			{
				ASSERT_EQ(got, -42);
				continue;
			}
			const double x = -20.0 * log10((double)vel / loudest);
			const int want = -(int)fmin(42.0, floor(x + 0.5));
			if (got != want)
			{
				ASSERT_TRUE(fabs(x - floor(x) - 0.5) < 0.005);
				ASSERT_EQ(abs(got - want), 1);
				ties++;
			}
		}
	ASSERT_TRUE(ties <= 4);
	static const struct { uint8_t vel, loudest; int db; } want[] = {
		{ 127, 127, 0 }, { 100, 127, -2 }, { 64, 127, -6 }, { 40, 127, -10 }, { 20, 127, -16 },
		{ 10, 127, -22 }, { 3, 127, -33 }, { 1, 127, -42 }, { 0, 127, -42 }, { 60, 120, -6 },
		{ 60, 127, -7 }, { 90, 127, -3 }, { 100, 50, 0 }, { 0, 0, 0 },
	};
	for (unsigned k = 0; k < sizeof want / sizeof want[0]; k++)
		ASSERT_EQ(seqc_velDb(want[k].vel, want[k].loudest), want[k].db);
}

def vel_template(vel, db, pct):
    """plan v0.7 V7-4 in Python: vel x 10^(dB x pct / 2000), dB floored at -42, rounded half up,
    1..127; a vel of 0, dB >= 0 or pct 0 leave vel"""
    if vel == 0 or db >= 0 or pct == 0:
        return vel
    x = vel * 10 ** (max(db, -42) * pct / 2000.0)
    return max(1, min(127, int(math.floor(x + 0.5))))

def trig_frames(path, voice):
    """the frame of each hit of voice in a --trig-log, as emu_onsets.py reads it: the last record of
    each block serial, at its time + 128 frames; the one-shot records are left out"""
    last, order = {}, []
    with open(path) as f:
        for line in f:
            w = line.split()
            if len(w) != 6 or int(w[1]) != voice or w[2] == 'oneshot':
                continue
            if w[3] not in last:
                order.append(w[3])
            last[w[3]] = int(w[0]) * 113 / 552960.0 + 128
    return [last[s] for s in order]

def hit_peaks(wav, channel, frames, before=8, after=220):
    """the largest |sample| of channel from before frames ahead of each frame to after frames past
    it; the hits whose window passes the end are left out"""
    ch, a = samples(wav)
    c = ('L1', 'R1', 'L2', 'R2').index(channel)
    total = len(a) // ch
    out = []
    for f in frames:
        lo, hi = int(f) - before, int(f) + after
        if hi > total:
            break
        out.append(max(abs(a[i * ch + c]) for i in range(lo, hi)))
    return out
