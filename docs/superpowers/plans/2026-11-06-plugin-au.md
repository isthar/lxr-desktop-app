# LICHOMAT plugin E9.7: an Audio Unit v2 instrument beside the VST3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build draft §8 on branch `plugin-v07`: `LICHOMAT.component`, an Audio Unit v2 instrument (type `aumu`) "LICHOMAT" by "LICHOMAT" for Logic and every other AU host, which offers what `LICHOMAT.vst3` 0.2.0 offers (the engine process per instance, the two stereo outputs with Out 1 the sum until Out 2 is used, the 36 automatable parameters with the firmware's own changes reported back, the state in the set, the latency, offline rendering, the real-time rule), tested in-process without installing anything, and validated by Apple's `auval` in the owner's install.

**Architecture:** A thin AU layer of our own, `plugin/au/au_unit.cpp`, a `MusicDeviceBase` of Apple's AudioUnitSDK 1.4.0 (vendored and pinned as the VST 3 SDK is), holds the VST3's own processor (`lichomat::Processor`, compiled into the component) and turns the AU's calls into its `process()`: notes into events at their offsets, parameter sets and scheduled events into points, the host callbacks into a process context, the two output elements into its two buses (Out 2 split while the host renders it), its output parameter changes into the AU's parameter values and, off the render thread, listener notifications; the ClassInfo carries the processor's state bytes. A test host of its own, `lichomat-auhost`, registers the component's factory in its own process (`AudioComponentRegister`) and plays `lichomat-plughost`'s plans, so that every VST3 scenario runs through the AU with the same checks.

**Tech Stack:** as E9.4: C11 and C++17 with Apple clang 21 (Command Line Tools 26.6, no Xcode), CMake 3.31, Ninja, ctest, the vendored VST 3 SDK 3.8.1 build 84 (MIT); new: Apple's AudioUnitSDK 1.4.0 (Apache-2.0, C++23), AudioToolbox's AU API (`AudioComponentRegister`, `AUEventListener`), Python 3 (`plistlib`), bash, `auval` (the owner's install only).

## Draft deviations and refinements

1. **Draft §8.2 chose by the build, the plan by the behaviour.** `auwrapper` does build without Xcode (M3), so the draft's condition for the second way ("if that does not work") is not what decided: its buses, offline mode, reports and real-time behaviour do not meet E9.4's (A-2).
2. **"The same two outputs" (§8.1) means Out 2 used when rendered** (A-7): an AU host has no activation to send. Whether Logic renders Out 2 of a "Multi-Output" instrument before an aux takes it is the owner's check P11 (c).
3. **`auval` cannot run on a staged copy** (§8.3 "as the Steinberg validator"): it validates the installed component, so the install puts the component in place first and takes it out again on a failure (A-20).
4. **The vendored SDK is 30 files, 348 KB** of the 50 files, 668 KB downloaded (§8): only what is compiled and its licence (A-3).
5. **The AU's latency follows the host's maximum frames per render**, not its blocks (A-14): a host that sets it larger than its blocks gets a larger, compensated latency.
6. **Version 0.2.0 for both formats** (A-6): §8 names none; the AU is E9.4's plugin in a second format.
7. **The AU is not sandbox safe** (A-12): GarageBand or another sandboxed host may run it out of its process or refuse it; P11 uses Logic or Live.
8. **Draft §8.5 "if you have no AU host, auval's result is enough"**: `auval` checks the AU's API, not the two outputs, the automation or the state; without an AU host, P11 (a) is done and (b)–(d) stay open (Risks).

Read in E9.4's end state (the scratch base, the files of `build/wt-plugin-v07` after Task 10), in `build/AudioUnitSDK` (the vendored copy has the same paths under `plugin/third_party/AudioUnitSDK/`) and in `build/vst3sdk`; line numbers are of those trees.

- **F1 The SDK's render.** `RenderBus()` calls `Render()` only for a new time stamp (`NeedsToRender()`, `include/AudioUnitSDK/AUBase.h:214-222`, `:707-714`); with more than one output element every element renders into its own cache buffer and the host's buffer gets a copy (`AUBase.h:658-683`), so one render of a cycle fills both outputs and the second element's pull only copies. The dispatcher takes no lock in the render-time methods (`GetParameter`, `SetParameter`, `ScheduleParameters`, `Render`, `MIDIEvent`: `src/AudioUnitSDK/AUPlugInDispatch.cpp:271-320`, `:469-545`).

- **F17 The processor after E9.4's reviews** (`plugin-buses-parameters.md`, "Changes during execution"), as the AU meets it. A `setState()` counts a restore generation (`restoreGen`), which `setActive(true)` passes to `EngineLink::start()` and a `setState()` while active to `restart()` (`spawnedGen`, `engineGen()`); `process()` takes a new engine only if it plays the card of the state restored last, and `setActive(true)` reads the generation again after it starts one. A new engine's slave and the host's notes are held `holdFrames` (`ceil(rate × 1,024 / 48,000)`) after its first report when that report gave it values it lacked (not for the first engine of an offline activation). A flush (0 frames) or a block with no Out 1 only takes the host's changes; they are `pending` (`plug_paramsPending()`) and reach the engine at the next block's first frame, after its transport messages. ## Real-time safety of the render thread

The prototype's rules hold (P-23, E9.4's "Real-time safety"). On the render thread the AU adds to the processor's `process()`:
- `HandleNoteOn()`/`HandleNoteOff()`: a store into `AuEvents` (1,024 events);
- `ScheduleParameter()`: a copy into `schedule` (256 events) and the AU's value (`SetParameterRT`, an atomic store into a parameter that exists);
- `SetParameter()`: the AU's value and one release store into the parameter's slot (any thread);
- the render: 36 acquire loads of the slots, the points into `AuParamChanges` (64 queues of 64 points), the host callbacks, `PrepareBuffer()` of the other element (its own memory), `activateBus()` when Out 2's use changes (an atomic store), the reports' `SetParameterRT` and relaxed flag stores.

No allocation, lock, wait or system call. The notifier thread calls `AUParameterListenerNotify()` (which locks) off the render thread. Offline the processor waits as before (P-14).

**The check:** `lichomat-auhost` marks for `plug_rtcheck` every call it makes on its render thread, as a host does them: the echo's `AudioUnitSetParameter()`, `AudioUnitScheduleParameters()`, `MusicDeviceMIDIEvent()` and `AudioUnitRender()` of Out 1 (and Out 2). `P13_au_rt` and `P13_au_rtparams` (the VST3's cases through the AU): expected 3,750 renders, 0 forbidden calls, 3,750 writes.

 * plug_au.h
 *
 * The AU's view of the plugin (plan E9.7 Task 3): pure functions that the AU
 * (plugin/au/au_unit.cpp) and its tests share.
 *
 * Parameters. The AU's parameters are the VST3's: the read-only "Engine" (id 0) and the 36 of

 * firmware's value plus the parameter's offset (a pan -63..64, the pattern 1..64); a voice's output
 * (0..6) and the engine's state (0..3) are indexed, with their names.
 *
 * Out 2. AU v2 has no bus activation: Out 2 counts as used while the host renders it. Each render
 * cycle (a new time stamp) asks plug_auRender() whether Out 1 and Out 2 are the device's two
 * outputs (the host rendered Out 2 in one of the last PLUG_AU_OUT2_CYCLES cycles) or Out 1 is
 * their sum, as the VST3's Out 1 while the host has not activated Out 2.
 *
 * Copyright (C) 2026 Tomasz Krzywicki
 * SPDX-License-Identifier: GPL-3.0-only
 *
 * Licensed under the GNU General Public License version 3, with the additional
 * permission and terms in NOTICE.md. See LICENSE and NOTICE.md in the root of
 * the repository.

#define PLUG_AU_H_

extern "C" {
#endif

#define PLUG_AU_ENGINE 0u			/**< the id of the read-only parameter "Engine" */

/** parameter i's value of an AU value: the nearest, within 0..max; not a number is 0 */
uint8_t plug_auPlain(unsigned i, double value);

{

} plug_auBuses_t;

 * plug_au.c
 *
 * The AU's view of the plugin (plan E9.7 Task 3); see plug_au.h.
 *
 * Copyright (C) 2026 Tomasz Krzywicki
 * SPDX-License-Identifier: GPL-3.0-only
 *

#include <math.h>

float plug_auValue(unsigned i, uint8_t v)
{
	return (float)((int)v + plug_params[i].offset);
}

uint8_t plug_auPlain(unsigned i, double value)
{
	const double v = floor(value - plug_params[i].offset + 0.5);
	if (!(v > 0.0))
		return 0;	/* also not a number */
	return (uint8_t)(v >= plug_params[i].max ? plug_params[i].max : v);
}

int plug_auRender(plug_auBuses_t *b)
{
	b->cycles++;
	return b->pulled != 0 && b->cycles - b->pulled <= PLUG_AU_OUT2_CYCLES;
}

void plug_auPulled(plug_auBuses_t *b)
{
	b->pulled = b->cycles;
}

/** one parameter's points of a cycle, at most kMax (more are dropped) */
class AuParamQueue
: public Steinberg::U::ImplementsNonDestroyable<Steinberg::U::Directly<Steinberg::Vst::IParamValueQueue>>
{
public:
	static constexpr Steinberg::int32 kMax = 64;

	Steinberg::Vst::ParamID PLUGIN_API getParameterId () override { return id; }
	Steinberg::int32 PLUGIN_API getPointCount () override { return count; }

	Steinberg::tresult PLUGIN_API getPoint (Steinberg::int32 index, Steinberg::int32& offset,
	                                        Steinberg::Vst::ParamValue& value) override
	{
		if (index < 0 || index >= count)
			return Steinberg::kInvalidArgument;
		offset = offsets[index];
		value = values[index];
		return Steinberg::kResultOk;
	}

	/* in the order of the offsets, after the points of the same offset */
	Steinberg::tresult PLUGIN_API addPoint (Steinberg::int32 offset, Steinberg::Vst::ParamValue value,
	                                        Steinberg::int32& index) override
	{
		if (count >= kMax)
			return Steinberg::kResultFalse;
		Steinberg::int32 k = count++;
		while (k > 0 && offsets[k - 1] > offset)
		{
			offsets[k] = offsets[k - 1];
			values[k] = values[k - 1];
			k--;
		}
		offsets[k] = offset;
		values[k] = value;
		index = k;
		return Steinberg::kResultOk;
	}

	Steinberg::Vst::ParamID id = 0;
	Steinberg::int32 count = 0;

private:
	Steinberg::int32 offsets[kMax] {};
	Steinberg::Vst::ParamValue values[kMax] {};
};

class AuParamChanges
: public Steinberg::U::ImplementsNonDestroyable<Steinberg::U::Directly<Steinberg::Vst::IParameterChanges>>

public:
	static constexpr Steinberg::int32 kMax = 64;	/**< more than the plugin's 37 parameters */

	Steinberg::int32 PLUGIN_API getParameterCount () override { return count; }

	Steinberg::Vst::IParamValueQueue* PLUGIN_API getParameterData (Steinberg::int32 index) override
	{
		return index >= 0 && index < count ? &queues[index] : nullptr;
	}

	Steinberg::Vst::IParamValueQueue* PLUGIN_API addParameterData (const Steinberg::Vst::ParamID& id,
	                                                               Steinberg::int32& index) override
	{
		for (Steinberg::int32 k = 0; k < count; k++)
			if (queues[k].id == id)
			{
				index = k;
				return &queues[k];
			}
		if (count >= kMax)
			return nullptr;
		index = count;
		queues[count].id = id;
		queues[count].count = 0;
		return &queues[count++];
	}

	/** a point of parameter id */
	void add (Steinberg::Vst::ParamID id, Steinberg::int32 offset, Steinberg::Vst::ParamValue value)
	{
		Steinberg::int32 index = 0, point = 0;
		if (Steinberg::Vst::IParamValueQueue* q = addParameterData (id, index))
			q->addPoint (offset, value, point);
	}

	void clear () { count = 0; }

private:
	AuParamQueue queues[kMax];
	Steinberg::int32 count = 0;
};

	{

			return false;
		const plug_param_t& p = plug_params[i];
		for (int k = 0; p.names && k <= p.max; k++)
			if (!strcmp (text, p.names[k]))
			{

				return true;
			}

			return false;

		if (CallHostBeatAndTempo (&beat, &tempo) == noErr)
		{
			c.state |= ProcessContext::kTempoValid | ProcessContext::kProjectTimeMusicValid;
			c.tempo = tempo;
			c.projectTimeMusic = beat;
		}
		Boolean playing = false, recording = false, changed = false, cycling = false;
		Float64 sample = 0.0, cycleStart = 0.0, cycleEnd = 0.0;
		const HostCallbackInfo& h = GetHostCallbackInfo ();
		const OSStatus t = h.transportStateProc2
		                       ? h.transportStateProc2 (h.hostUserData, &playing, &recording, &changed, &sample, &cycling,
		                                                &cycleStart, &cycleEnd)
		                       : CallHostTransportState (&playing, &changed, &sample, &cycling, &cycleStart, &cycleEnd);
		if (t != noErr)
			return;	/* no transport: the sequencer does not follow (README) */
		if (playing)
			c.state |= ProcessContext::kPlaying;
		if (cycling)
			c.state |= ProcessContext::kCycleActive | ProcessContext::kCycleValid;
		c.cycleStartMusic = cycleStart;
		c.cycleEndMusic = cycleEnd;
		c.projectTimeSamples = (TSamples)sample;
	}

	/* the host's parameter sets and scheduled events of this cycle as the processor's points */
	void hostPoints (UInt32 n)
	{
		const int32 last = n > 0 ? (int32)n - 1 : 0;
		for (unsigned i = 0; i < PLUG_PARAM_COUNT; i++)
		{
			const uint64_t s = slots[i].load (std::memory_order_acquire);
			const uint32_t gen = (uint32_t)(s >> 40);
			if (gen == seen[i])
				continue;
			seen[i] = gen;
			const int32 at = (int32)((s >> 8) & 0xFFFFFFu);
			inParams.add (plug_params[i].id, at > last ? last : at, (double)(s & 0xFFu) / plug_params[i].max);
		}
		for (UInt32 k = 0; k < scheduled; k++)
		{
			const AudioUnitParameterEvent& e = schedule[k];
			const unsigned i = (unsigned)plug_paramIndex (e.parameter);
			const double max = plug_params[i].max;
			if (e.eventType == kParameterEvent_Immediate)
			{
				const int32 at = (int32)e.eventValues.immediate.bufferOffset;
				inParams.add (e.parameter, at > last ? last : at, plug_auPlain (i, e.eventValues.immediate.value) / max);
				continue;
			}
			/* a ramp: its value at the cycle's first frame it covers and at its last */
			const auto& r = e.eventValues.ramp;
			const double d = r.durationInFrames > 0 ? (double)r.durationInFrames : 1.0;
			const int32 a = r.startBufferOffset < 0 ? 0 : r.startBufferOffset > last ? last : r.startBufferOffset;
			const int64_t endAt = (int64_t)r.startBufferOffset + (int64_t)r.durationInFrames - 1;
			const int32 b = endAt < a ? a : endAt > last ? last : (int32)endAt;
			const auto at = [&] (int32 f) {
				const double x = ((double)f - r.startBufferOffset) / d;
				return r.startValue + (r.endValue - r.startValue) * (x < 0.0 ? 0.0 : x > 1.0 ? 1.0 : x);
			};
			inParams.add (e.parameter, a, plug_auPlain (i, at (a)) / max);
			if (b > a)
				inParams.add (e.parameter, b, plug_auPlain (i, b == endAt ? r.endValue : at (b)) / max);
		}
		scheduled = 0;
	}

	/* the values the processor reported: into the AU's own, and the host's listeners are told */
	void takeReports ()
	{
		for (int32 q = 0; q < outParams.getParameterCount (); q++)
		{
			IParamValueQueue* pq = outParams.getParameterData (q);
			int32 off = 0;
			ParamValue v = 0.0;
			const int32 np = pq ? pq->getPointCount () : 0;
			if (np < 1 || pq->getPoint (np - 1, off, v) != kResultOk)
				continue;
			const ParamID id = pq->getParameterId ();
			const int i = plug_paramIndex (id);
			if (id == lichomat::kParamEngine)
			{
				Globals ()->SetParameterRT (PLUG_AU_ENGINE, (float)lround (v * 3.0));
				pending[PLUG_PARAM_COUNT].store (true, std::memory_order_relaxed);
			}
			else if (i >= 0)
			{
				Globals ()->SetParameterRT (id, plug_auValue ((unsigned)i, plug_paramValue ((unsigned)i, v)));
				pending[i].store (true, std::memory_order_relaxed);
			}
		}
	}

	void render (UInt32 bus, UInt32 n)
	{
		const UInt32 outs = Outputs ().GetNumberOfElements ();
		const bool split = plug_auRender (&buses) && outs > 1;
		if (split != out2)
		{
			proc->activateBus (kAudio, kOutput, 1, split);	/* an atomic store in the processor */
			out2 = split;
		}
		float* ch[2][2];
		for (UInt32 b = 0; b < 2; b++)
		{
			if (b < outs)
			{
				AudioBufferList& l = b == bus ? Output (b).GetBufferList () : Output (b).PrepareBuffer (n);
				ch[b][0] = static_cast<float*> (l.mBuffers[0].mData);
				ch[b][1] = static_cast<float*> (l.mBuffers[1].mData);
			}
			else
			{
				ch[b][0] = spare.data ();
				ch[b][1] = spare.data () + maxFrames;
			}
		}
		hostPoints (n);
		ProcessContext ctx;
		hostContext (ctx);
		AudioBusBuffers out[2] {};
		for (int b = 0; b < 2; b++)
		{
			out[b].numChannels = 2;
			out[b].channelBuffers32 = ch[b];
		}
		ProcessData d;
		d.processMode = offline ? kOffline : kRealtime;
		d.symbolicSampleSize = kSample32;
		d.numSamples = (int32)n;
		d.numInputs = 0;
		d.numOutputs = 2;
		d.outputs = out;
		d.inputParameterChanges = &inParams;
		d.outputParameterChanges = &outParams;
		d.inputEvents = &events;
		d.processContext = &ctx;
		proc->process (d);
		takeReports ();
		events.clear ();
		inParams.clear ();
		outParams.clear ();
	}

	/* off the render thread: the host's listeners learn of each value the processor reported */
	void notifyLoop ()
	{
		while (!stopNotify.load ())
		{
			for (unsigned k = 0; k < kSlots; k++)
				if (pending[k].exchange (false, std::memory_order_relaxed))
				{
					AudioUnitParameter p {GetComponentInstance (), k < PLUG_PARAM_COUNT ? plug_params[k].id : PLUG_AU_ENGINE,
					                      kAudioUnitScope_Global, 0};
					AUParameterListenerNotify (nullptr, nullptr, &p);
				}
			std::this_thread::sleep_for (std::chrono::milliseconds (20));
		}
	}

inline Plan readPlan (const char* path, const Extra& extra = nullptr)
{
	std::ifstream f (path);
	if (!f)
		die (std::string ("cannot read ") + path);
	Plan p;
	std::string line;
	while (std::getline (f, line))
	{
		std::istringstream s (line.substr (0, line.find ('#')));
		std::string cmd;
		if (!(s >> cmd))
			continue;
		bool ok = true;
		if (extra && extra (cmd, s, ok)) { /* the host's own command */ }
		else if (cmd == "bundle") ok = !!(s >> p.bundle);
		else if (cmd == "rate") ok = !!(s >> p.rate);
		else if (cmd == "block") ok = !!(s >> p.block);
		else if (cmd == "frames") ok = !!(s >> p.frames);
		else if (cmd == "instances") ok = !!(s >> p.instances);
		else if (cmd == "card") ok = !!(s >> p.card);
		else if (cmd == "state-in") ok = !!(s >> p.stateIn);
		else if (cmd == "state-out") ok = !!(s >> p.stateOut);
		else if (cmd == "out") ok = !!(s >> p.out);
		else if (cmd == "script") ok = !!(s >> p.script);
		else if (cmd == "rtcheck") p.rtcheck = true;
		else if (cmd == "paced") p.paced = true;
		else if (cmd == "bus2") p.bus2 = true;
		else if (cmd == "echo") p.echo = true;
		else if (cmd == "channel") ok = !!(s >> p.channel) && p.channel >= 0 && p.channel < 16;
		else if (cmd == "param")
		{
			ParamCmd c;
			ok = !!(s >> c.frame >> c.id >> c.value) && plug_paramIndex (c.id) >= 0 && c.value >= 0
			     && c.value <= plug_params[plug_paramIndex (c.id)].max;
			p.params.push_back (c);
		}
		else if (cmd == "mode") { std::string m; ok = !!(s >> m) && (m == "realtime" || m == "offline"); p.offline = m == "offline"; }
		else if (cmd == "loop") ok = !!(s >> p.loopStart >> p.loopEnd), p.loop = true;
		else if (cmd == "note") { NoteCmd n; ok = !!(s >> n.frame >> n.ch >> n.pitch >> n.vel); p.notes.push_back (n); }
		else if (cmd == "play") { TransportCmd t {0, TransportCmd::Play, 0, 0}; ok = !!(s >> t.frame >> t.tempo >> t.ppq); p.transport.push_back (t); }
		else if (cmd == "stop") { TransportCmd t {0, TransportCmd::Stop, 0, 0}; ok = !!(s >> t.frame); p.transport.push_back (t); }
		else if (cmd == "tempo") { TransportCmd t {0, TransportCmd::Tempo, 0, 0}; ok = !!(s >> t.frame >> t.tempo); p.transport.push_back (t); }
		else if (cmd == "kill") { uint64_t k; ok = !!(s >> k); p.kills.push_back (k); }
		else if (cmd == "hang") { uint64_t k; ok = !!(s >> k); p.hangs.push_back (k); }
		else if (cmd == "renew") { uint64_t k; int i; ok = !!(s >> k >> i); p.renews.push_back ({k, i}); }
		else if (cmd == "flush")
		{
			ParamCmd c;
			ok = !!(s >> c.frame >> c.id >> c.value) && plug_paramIndex (c.id) >= 0 && c.value >= 0
			     && c.value <= plug_params[plug_paramIndex (c.id)].max;
			p.flushes.push_back (c);
		}
		else if (cmd == "flush-empty") { uint64_t k; ok = !!(s >> k); p.emptyFlushes.push_back (k); }
		else if (cmd == "param-at")
		{
			Plan::RawPoint c;
			long long o = 0;
			ok = !!(s >> c.frame >> o >> c.id >> c.value) && plug_paramIndex (c.id) >= 0 && c.value >= 0
			     && c.value <= plug_params[plug_paramIndex (c.id)].max && o >= INT32_MIN && o <= INT32_MAX;
			c.offset = (int32_t)o;
			p.rawPoints.push_back (c);
		}
		else if (cmd == "controller") ok = !!(s >> p.controller);
		else if (cmd == "events") ok = !!(s >> p.events);
		else if (cmd == "state-early") ok = !!(s >> p.stateEarly);
		else if (cmd == "no-outputs") { uint64_t k; ok = !!(s >> k); p.noOutputs.push_back (k); }
		else if (cmd == "null-out2") p.nullOut2 = true;
		else if (cmd == "null-out2-left") p.nullOut2Left = true;
		else if (cmd == "null-out1") { uint64_t k; ok = !!(s >> k); p.nullOut1.push_back (k); }

	return p;
}

/* the host's transport, as Live gives it: the position at a block's first frame, wrapped at the
 * loop's end, the tempo of the block's first frame */
struct Timeline
{
	const Plan& p;
	bool playing = false;
	double tempo = 120.0, pos = 0.0;
	size_t next = 0;

	explicit Timeline (const Plan& plan) : p (plan) {}

	/* the context of the block at frame, then the position advanced over frames n */
	plug_transport_t block (uint64_t frame, uint32_t n)
	{
		while (next < p.transport.size () && p.transport[next].frame <= frame)
		{
			const TransportCmd& t = p.transport[next++];
			if (t.kind == TransportCmd::Play) { playing = true; tempo = t.tempo; pos = t.ppq; }
			else if (t.kind == TransportCmd::Stop) playing = false;
			else tempo = t.tempo;
		}
		plug_transport_t t {1, playing ? 1 : 0, tempo, pos, p.loop ? 1 : 0, p.loopStart, p.loopEnd};
		if (playing)
		{
			pos += (double)n * tempo / (60.0 * p.rate);
			if (p.loop && p.loopEnd > p.loopStart && t.ppq < p.loopEnd && pos >= p.loopEnd)
				pos = p.loopStart + std::fmod (pos - p.loopEnd, p.loopEnd - p.loopStart);
		}
		return t;
	}
};

/* paced, the host's thread plays as an audio device's does: a time-constraint thread of the block's
 * period, a quarter of it to compute (app_mach.c:106-117, as the engine's), woken at each block's
 * time with mach_wait_until(); a normal thread's long sleep may end milliseconds late (timer
 * coalescing), and two blocks back to back give the engine no time between them */
inline void paceAsDevice (const Plan& p)
{
	mach_timebase_info_data_t tb;
	mach_timebase_info (&tb);
	thread_time_constraint_policy_data_t pol;
	pol.period = (uint32_t)((double)p.block / p.rate * 1e9 * (double)tb.denom / (double)tb.numer);
	pol.computation = pol.period / 4u;
	pol.constraint = pol.period;
	pol.preemptible = 1;
	if (thread_policy_set (pthread_mach_thread_np (pthread_self ()), THREAD_TIME_CONSTRAINT_POLICY, (thread_policy_t)&pol,
	                       THREAD_TIME_CONSTRAINT_POLICY_COUNT) != KERN_SUCCESS)
		fprintf (stderr, "%s: the time-constraint policy was refused; pacing as a normal thread\n", gName);
}

/* mach_absolute_time() at wall time t0 + seconds */
inline uint64_t machAt (uint64_t t0, double seconds)
{
	mach_timebase_info_data_t tb;
	mach_timebase_info (&tb);
	return t0 + (uint64_t)(seconds * 1e9 * (double)tb.denom / (double)tb.numer);
}

/* sig to every child of this process: the engines */
inline void signalEngines (int sig)
{
	pid_t kids[64];
	memset (kids, 0, sizeof kids);
	(void)proc_listchildpids (getpid (), kids, sizeof kids);
	for (pid_t k : kids)
		if (k > 0)
			kill (k, sig);
}

	return transportState2 (user, playing, nullptr, changed, sample, cycling, cycleStart, cycleEnd);
}

std::string cfText (CFStringRef s)
{
	char b[256] = "";
	if (s)
		CFStringGetCString (s, b, sizeof b, kCFStringEncodingUTF8);
	return b;
}

OSType fourcc (const std::string& s)
{
	if (s.size () != 4)
		die ("a four-character code is \"" + s + "\"");
	return (OSType)((uint8_t)s[0] << 24 | (uint8_t)s[1] << 16 | (uint8_t)s[2] << 8 | (uint8_t)s[3]);
}

/* the bundle's one AudioComponents entry, registered for this process */
AudioComponent load (const std::string& path, AudioComponentDescription& desc)
{
	CFURLRef url = CFURLCreateFromFileSystemRepresentation (nullptr, (const UInt8*)path.c_str (), (CFIndex)path.size (), true);
	CFBundleRef bundle = url ? CFBundleCreate (nullptr, url) : nullptr;
	if (url)
		CFRelease (url);
	if (!bundle)
		die ("cannot open the bundle " + path);
	CFArrayRef comps = (CFArrayRef)CFBundleGetValueForInfoDictionaryKey (bundle, CFSTR ("AudioComponents"));
	if (!comps || CFGetTypeID (comps) != CFArrayGetTypeID () || CFArrayGetCount (comps) != 1)
		die ("the bundle has not one AudioComponents entry");
	CFDictionaryRef d = (CFDictionaryRef)CFArrayGetValueAtIndex (comps, 0);
	auto text = [d] (CFStringRef key) {
		CFTypeRef v = CFDictionaryGetValue (d, key);
		return v && CFGetTypeID (v) == CFStringGetTypeID () ? cfText ((CFStringRef)v) : std::string ();
	};
	SInt32 version = 0;
	CFTypeRef v = CFDictionaryGetValue (d, CFSTR ("version"));
	if (!v || CFGetTypeID (v) != CFNumberGetTypeID () || !CFNumberGetValue ((CFNumberRef)v, kCFNumberSInt32Type, &version))
		die ("the AudioComponents entry has no version");
	desc = AudioComponentDescription {fourcc (text (CFSTR ("type"))), fourcc (text (CFSTR ("subtype"))),
	                                  fourcc (text (CFSTR ("manufacturer"))), 0, 0};
	const std::string name = text (CFSTR ("name")), factory = text (CFSTR ("factoryFunction"));
	CFErrorRef err = nullptr;
	if (!CFBundleLoadExecutableAndReturnError (bundle, &err))
		die ("cannot load the bundle's executable");
	CFStringRef fn = CFStringCreateWithCString (nullptr, factory.c_str (), kCFStringEncodingUTF8);
	void* f = CFBundleGetFunctionPointerForName (bundle, fn);
	CFRelease (fn);
	if (!f)
		die ("the bundle exports no " + factory);
	CFStringRef cname = CFStringCreateWithCString (nullptr, name.c_str (), kCFStringEncodingUTF8);
	AudioComponent c = AudioComponentRegister (&desc, cname, (UInt32)version, (AudioComponentFactoryFunction)f);
	CFRelease (cname);
	if (!c)
		die ("AudioComponentRegister refused the component");
	printf ("%s: component %s %s %s \"%s\", version %d.%d.%d, factory %s\n", gName, text (CFSTR ("type")).c_str (),
	        text (CFSTR ("subtype")).c_str (), text (CFSTR ("manufacturer")).c_str (), name.c_str (), version >> 16,
	        (version >> 8) & 255, version & 255, factory.c_str ());
	return c;
}

/* the values the host's listener heard of, by parameter id */
struct Heard
{
	std::mutex m;
	std::map<uint32_t, int> count;
};

struct Instance
{
	AudioComponentInstance au = nullptr;
	double engine = 0.0;	/* the Engine parameter: 2 running */
	std::vector<float> l, r, l2, r2;
	std::vector<float> out[4];	/* a block of L1 R1 L2 R2 */
	uint32_t latency = 0;
	plug_params_t mirror {};	/* the plugin's step with its engine, for the script (plug_params.h) */
	ParameterChanges points {64};	/* the block's points of the host, as the processor takes them */
	std::vector<std::pair<uint32_t, float>> echo;	/* reported values for the next block */
	float shown[PLUG_PARAM_COUNT] {};	/* the AU's values the host knows */
	bool first = true;
	int waits = 0;
	AUEventListenerRef listener = nullptr;
	std::shared_ptr<Heard> heard = std::make_shared<Heard> ();
};

void set (Instance& in, AudioUnitPropertyID id, AudioUnitScope scope, AudioUnitElement el, const void* v, UInt32 size,
          const char* what)
{
	const OSStatus r = AudioUnitSetProperty (in.au, id, scope, el, v, size);
	if (r != noErr)
		die (std::string (what) + " refused: " + std::to_string ((int)r));
}

/* the ClassInfo of a state: the plugin's bytes with the keys every AU's state has */
CFDictionaryRef classInfo (const AudioComponentDescription& desc, const std::vector<uint8_t>& state)
{
	CFMutableDictionaryRef d = CFDictionaryCreateMutable (nullptr, 0, &kCFTypeDictionaryKeyCallBacks,
	                                                      &kCFTypeDictionaryValueCallBacks);
	const SInt32 nums[4] = {0, (SInt32)desc.componentType, (SInt32)desc.componentSubType, (SInt32)desc.componentManufacturer};
	const CFStringRef keys[4] = {CFSTR ("version"), CFSTR ("type"), CFSTR ("subtype"), CFSTR ("manufacturer")};
	for (int k = 0; k < 4; k++)
	{
		CFNumberRef n = CFNumberCreate (nullptr, kCFNumberSInt32Type, &nums[k]);
		CFDictionarySetValue (d, keys[k], n);
		CFRelease (n);
	}
	CFDictionarySetValue (d, CFSTR ("name"), CFSTR ("Untitled"));
	CFDataRef data = CFDataCreate (nullptr, state.data (), (CFIndex)state.size ());
	CFDictionarySetValue (d, kStateKey, data);
	CFRelease (data);
	return d;
}

std::vector<uint8_t> cardState (const std::string& card)
{
	std::vector<uint8_t> out;
	char err[512];
	auto put = [] (void* ctx, const void* p, size_t n) {
		auto* v = static_cast<std::vector<uint8_t>*> (ctx);
		v->insert (v->end (), static_cast<const uint8_t*> (p), static_cast<const uint8_t*> (p) + n);
		return 0;
	};
	if (plug_archiveWrite (card.c_str (), put, &out, err, sizeof err) != 0)
		die (err);
	return out;
}

float param (const Instance& in, AudioUnitParameterID id)

	AudioUnitParameterValue v = 0.0f;
	if (AudioUnitGetParameter (in.au, id, kAudioUnitScope_Global, 0, &v) != noErr)
		die ("AudioUnitGetParameter " + std::to_string (id));
	return v;
}

/* the AU's parameters, outputs, latency and tail */
void printInfo (const Instance& in, double rate)
{
	UInt32 size = 0;
	Boolean w = false;
	if (AudioUnitGetPropertyInfo (in.au, kAudioUnitProperty_ParameterList, kAudioUnitScope_Global, 0, &size, &w) != noErr)
		die ("no parameter list");
	std::vector<AudioUnitParameterID> ids (size / sizeof (AudioUnitParameterID));
	AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterList, kAudioUnitScope_Global, 0, ids.data (), &size);
	for (AudioUnitParameterID id : ids)
	{
		AudioUnitParameterInfo p {};
		size = sizeof p;
		if (AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterInfo, kAudioUnitScope_Global, id, &p, &size) != noErr)
			die ("no ParameterInfo of " + std::to_string (id));
		std::string strings = "-";
		CFArrayRef a = nullptr;
		size = sizeof a;
		if (AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterValueStrings, kAudioUnitScope_Global, id, &a, &size) == noErr && a)
		{
			strings.clear ();
			for (CFIndex k = 0; k < CFArrayGetCount (a); k++)
				strings += (k ? "|" : "") + cfText ((CFStringRef)CFArrayGetValueAtIndex (a, k));
			CFRelease (a);
		}
		std::string shows;
		for (float v : {p.minValue, p.defaultValue, p.maxValue})
		{
			AudioUnitParameterStringFromValue s {id, &v, nullptr};
			size = sizeof s;
			if (AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterStringFromValue, kAudioUnitScope_Global, 0, &s, &size) != noErr
			    || !s.outString)
				die ("no ParameterStringFromValue of " + std::to_string (id));
			shows += (shows.empty () ? "" : "|") + cfText (s.outString);
			AudioUnitParameterValueFromString back {id, s.outString, 0.0f};
			size = sizeof back;
			if ((p.flags & kAudioUnitParameterFlag_IsWritable)
			    && (AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterValueFromString, kAudioUnitScope_Global, 0, &back,
			                              &size) != noErr
			        || back.outValue != v))
				die ("ParameterValueFromString of " + std::to_string (id) + " does not give " + std::to_string (v) + " back");
			CFRelease (s.outString);
		}
		const std::string name = (p.flags & kAudioUnitParameterFlag_HasCFNameString) ? cfText (p.cfNameString) : p.name;
		if ((p.flags & kAudioUnitParameterFlag_CFNameRelease) && p.cfNameString)
			CFRelease (p.cfNameString);
		printf ("%s: info: param %u \"%s\" %g..%g default %g unit %u %s%s strings %s shows %s\n", gName, (unsigned)id,
		        name.c_str (), p.minValue, p.maxValue, p.defaultValue, (unsigned)p.unit,
		        (p.flags & kAudioUnitParameterFlag_IsWritable) ? "rw" : "r",
		        (p.flags & kAudioUnitParameterFlag_ValuesHaveStrings) ? "s" : "", strings.c_str (), shows.c_str ());
	}
	UInt32 outs = 0;
	size = sizeof outs;
	AudioUnitGetProperty (in.au, kAudioUnitProperty_ElementCount, kAudioUnitScope_Output, 0, &outs, &size);
	std::string names;
	for (UInt32 b = 0; b < outs; b++)
	{
		CFStringRef n = nullptr;
		size = sizeof n;
		if (AudioUnitGetProperty (in.au, kAudioUnitProperty_ElementName, kAudioUnitScope_Output, b, &n, &size) == noErr && n)
		{
			names += (b ? ", " : "") + cfText (n);
			CFRelease (n);
		}
	}
	AUChannelInfo ch[4] {};
	size = sizeof ch;
	AudioUnitGetProperty (in.au, kAudioUnitProperty_SupportedNumChannels, kAudioUnitScope_Global, 0, ch, &size);
	Float64 lat = 0.0, tail = 0.0;
	size = sizeof lat;
	AudioUnitGetProperty (in.au, kAudioUnitProperty_Latency, kAudioUnitScope_Global, 0, &lat, &size);
	size = sizeof tail;
	AudioUnitGetProperty (in.au, kAudioUnitProperty_TailTime, kAudioUnitScope_Global, 0, &tail, &size);
	printf ("%s: info: outputs %u: %s; channels %d in, %d out; kAudioUnitProperty_Latency %.0f frames; TailTime %g s\n",
	        gName, (unsigned)outs, names.c_str (), ch[0].inChannels, ch[0].outChannels, lat * rate, tail);
}

/* a component at the plan's rate and block, with its state, initialized */
void open (Instance& in, AudioComponent comp, const AudioComponentDescription& desc, const Plan& p, const AuPlan& a)
{
	if (AudioComponentInstanceNew (comp, &in.au) != noErr)
		die ("AudioComponentInstanceNew failed");
	if (a.outputs != 2)
		set (in, kAudioUnitProperty_ElementCount, kAudioUnitScope_Output, 0, &a.outputs, sizeof a.outputs, "ElementCount");
	AudioStreamBasicDescription f {};
	f.mSampleRate = p.rate;
	f.mFormatID = kAudioFormatLinearPCM;
	f.mFormatFlags = kAudioFormatFlagsNativeFloatPacked | kAudioFormatFlagIsNonInterleaved;
	f.mBytesPerPacket = f.mBytesPerFrame = 4;
	f.mFramesPerPacket = 1;
	f.mChannelsPerFrame = 2;
	f.mBitsPerChannel = 32;
	for (UInt32 b = 0; b < a.outputs; b++)
		set (in, kAudioUnitProperty_StreamFormat, kAudioUnitScope_Output, b, &f, sizeof f, "StreamFormat");
	const UInt32 maxFrames = (UInt32)p.block;
	set (in, kAudioUnitProperty_MaximumFramesPerSlice, kAudioUnitScope_Global, 0, &maxFrames, sizeof maxFrames,
	     "MaximumFramesPerSlice");
	HostCallbackInfo cb {&gTime, beatAndTempo, nullptr, transportState, transportState2};
	set (in, kAudioUnitProperty_HostCallbacks, kAudioUnitScope_Global, 0, &cb, sizeof cb, "HostCallbacks");
	const UInt32 offline = p.offline ? 1 : 0;
	set (in, kAudioUnitProperty_OfflineRender, kAudioUnitScope_Global, 0, &offline, sizeof offline, "OfflineRender");
	std::vector<uint8_t> state;
	if (!p.stateIn.empty ())
		state = readFile (p.stateIn);
	else if (!p.card.empty ())
		state = cardState (p.card);
	if (!state.empty ())
	{
		CFDictionaryRef ci = classInfo (desc, state);
		const OSStatus r = AudioUnitSetProperty (in.au, kAudioUnitProperty_ClassInfo, kAudioUnitScope_Global, 0, &ci, sizeof ci);
		CFRelease (ci);
		if (r != noErr)
			die ("setState refused the card");
	}
	if (AudioUnitInitialize (in.au) != noErr)
		die ("AudioUnitInitialize failed");
	Float64 lat = 0.0;
	UInt32 size = sizeof lat;
	AudioUnitGetProperty (in.au, kAudioUnitProperty_Latency, kAudioUnitScope_Global, 0, &lat, &size);
	in.latency = (uint32_t)std::lround (lat * p.rate);
	for (int b = 0; b < 4; b++)
		in.out[b].assign ((size_t)p.block + 1, 0.0f);	/* + 1: the checks' render of one frame too many */
	/* the listener, as a host's view would have it */
	std::shared_ptr<Heard> heard = in.heard;
	AUEventListenerCreateWithDispatchQueue (&in.listener, 0.0f, 0.0f, dispatch_get_global_queue (QOS_CLASS_DEFAULT, 0),
	                                       ^(void*, const AudioUnitEvent* e, UInt64, AudioUnitParameterValue) {
		                                       std::lock_guard<std::mutex> g (heard->m);
		                                       heard->count[e->mArgument.mParameter.mParameterID]++;
	                                       });
	for (unsigned i = 0; i <= PLUG_PARAM_COUNT; i++)
	{
		AudioUnitEvent e {};
		e.mEventType = kAudioUnitEvent_ParameterValueChange;
		e.mArgument.mParameter = {in.au, i < PLUG_PARAM_COUNT ? plug_params[i].id : PLUG_AU_ENGINE, kAudioUnitScope_Global, 0};
		AUEventListenerAddEventType (in.listener, nullptr, &e);
	}
	for (unsigned i = 0; i < PLUG_PARAM_COUNT; i++)
		in.shown[i] = param (in, plug_params[i].id);
	in.engine = 0.0;
	in.first = true;
	plug_paramsInit (&in.mirror, 0);
	in.echo.clear ();
}

void close (Instance& in)
{
	if (in.listener)
		AUListenerDispose (in.listener);
	in.listener = nullptr;
	AudioUnitUninitialize (in.au);
	AudioComponentInstanceDispose (in.au);
	in.au = nullptr;
}

/* Out 1 (bus 0) or Out 2 (bus 1) of a block of n frames at sample time t into in.out */
OSStatus renderBus (Instance& in, UInt32 bus, UInt32 n, Float64 t)
{
	struct
	{
		AudioBufferList list;
		AudioBuffer second;
	} b {};
	b.list.mNumberBuffers = 2;
	for (UInt32 c = 0; c < 2; c++)
	{
		AudioBuffer& x = c == 0 ? b.list.mBuffers[0] : b.second;
		x.mNumberChannels = 1;
		x.mDataByteSize = n * 4u;
		x.mData = in.out[2 * bus + c].data ();
	}
	AudioTimeStamp ts {};
	ts.mSampleTime = t;
	ts.mFlags = kAudioTimeStampSampleTimeValid;
	AudioUnitRenderActionFlags flags = 0;
	return AudioUnitRender (in.au, &flags, &ts, bus, n, &b.list);
}

/* what auval checks of an instrument and this host can check (the plan's checks) */
void runChecks (Instance& in, const Plan& p, const AuPlan& a)
{
	int passed = 0;
	auto expect = [&passed] (bool ok, const std::string& what) {
		if (!ok)
			die ("checks: " + what);
		passed++;
	};
	/* initialized again at another rate and back: the latency follows the rate */
	for (double rate : {p.rate == 48000.0 ? 96000.0 : 48000.0, p.rate})
	{
		expect (AudioUnitUninitialize (in.au) == noErr, "AudioUnitUninitialize");
		AudioStreamBasicDescription f {};
		UInt32 size = sizeof f;
		AudioUnitGetProperty (in.au, kAudioUnitProperty_StreamFormat, kAudioUnitScope_Output, 0, &f, &size);
		f.mSampleRate = rate;
		for (UInt32 b = 0; b < a.outputs; b++)
			set (in, kAudioUnitProperty_StreamFormat, kAudioUnitScope_Output, b, &f, sizeof f, "StreamFormat");
		expect (AudioUnitInitialize (in.au) == noErr, "AudioUnitInitialize at " + std::to_string (rate));
		Float64 lat = 0.0;
		size = sizeof lat;
		AudioUnitGetProperty (in.au, kAudioUnitProperty_Latency, kAudioUnitScope_Global, 0, &lat, &size);
		const uint32_t want = plug_latency (rate, (uint32_t)p.block, plug_marginFromEnv ());
		expect (std::lround (lat * rate) == (long)want, "the latency at " + std::to_string (rate));
	}
	/* every writable parameter: its minimum, maximum and default, set and scheduled, read back */
	for (unsigned i = 0; i < PLUG_PARAM_COUNT; i++)
	{
		const AudioUnitParameterID id = plug_params[i].id;
		AudioUnitParameterInfo info {};
		UInt32 size = sizeof info;
		AudioUnitGetProperty (in.au, kAudioUnitProperty_ParameterInfo, kAudioUnitScope_Global, id, &info, &size);
		if ((info.flags & kAudioUnitParameterFlag_CFNameRelease) && info.cfNameString)
			CFRelease (info.cfNameString);
		for (float v : {info.minValue, info.maxValue, info.defaultValue})
		{
			expect (AudioUnitSetParameter (in.au, id, kAudioUnitScope_Global, 0, v, 0) == noErr && param (in, id) == v,
			        "set " + std::to_string (id));
			AudioUnitParameterEvent e {};
			e.scope = kAudioUnitScope_Global;
			e.parameter = id;
			e.eventType = kParameterEvent_Immediate;
			e.eventValues.immediate.value = v;
			expect (AudioUnitScheduleParameters (in.au, &e, 1) == noErr && param (in, id) == v, "scheduled " + std::to_string (id));
		}
		in.shown[i] = info.defaultValue;
	}
	expect (AudioUnitSetParameter (in.au, PLUG_AU_ENGINE, kAudioUnitScope_Global, 0, 1.0f, 0) != noErr, "the Engine took a set");
	/* more frames than the maximum: refused */
	expect (renderBus (in, 0, (UInt32)p.block + 1, -1000000.0) == kAudioUnitErr_TooManyFramesToProcess, "a render too long");
	/* the ClassInfo read and given back */
	CFPropertyListRef ci = nullptr;
	UInt32 size = sizeof ci;
	expect (AudioUnitGetProperty (in.au, kAudioUnitProperty_ClassInfo, kAudioUnitScope_Global, 0, &ci, &size) == noErr && ci,
	        "the ClassInfo read");
	expect (AudioUnitSetProperty (in.au, kAudioUnitProperty_ClassInfo, kAudioUnitScope_Global, 0, &ci, sizeof ci) == noErr,
	        "the ClassInfo given back");
	CFRelease (ci);
	printf ("%s: checks: %d passed\n", gName, passed);
}

/* 0-frame renders every 10 ms (each its own time stamp, before frame 0) until the engine runs */
void waitRunning (Instance& in)
{
	const auto t0 = std::chrono::steady_clock::now ();
	while (in.engine < 1.5)
	{
		renderBus (in, 0, 0, -1.0 - in.waits++);
		in.engine = param (in, PLUG_AU_ENGINE);
		if (std::chrono::steady_clock::now () - t0 > std::chrono::seconds (60))
			die ("the engine did not run within 60 s");
		std::this_thread::sleep_for (std::chrono::milliseconds (10));
	}
}

/* the values the AU shows after the block at frame: printed (every one after the first block, then
 * each that changed), into the mirror as the plugin's report, and kept for an echo */
void readReports (Instance& in, size_t i, uint64_t frame, bool echo)
{
	std::string line;
	in.engine = param (in, PLUG_AU_ENGINE);
	for (unsigned k = 0; k < PLUG_PARAM_COUNT; k++)
	{
		const float v = param (in, plug_params[k].id);
		if (!in.first && v == in.shown[k])
			continue;
		in.shown[k] = v;
		const uint8_t plain = plug_auPlain (k, v);
		line += " " + std::to_string (plug_params[k].id) + "=" + std::to_string (plain);
		in.mirror.p[k].want = in.mirror.p[k].sent = plain;
		in.mirror.p[k].shown = 1;
		if (echo)
			in.echo.push_back ({plug_params[k].id, v});
	}
	in.first = false;
	if (!line.empty ())
		printf ("%s: instance %zu: frame %llu:%s\n", gName, i, (unsigned long long)frame, line.c_str ());
}

std::vector<uint8_t> stateOf (Instance& in)
{
	CFPropertyListRef ci = nullptr;
	UInt32 size = sizeof ci;
	if (AudioUnitGetProperty (in.au, kAudioUnitProperty_ClassInfo, kAudioUnitScope_Global, 0, &ci, &size) != noErr || !ci)
		die ("getState failed");
	CFDictionaryRef d = (CFDictionaryRef)ci;
	std::vector<CFStringRef> keys ((size_t)CFDictionaryGetCount (d));
	CFDictionaryGetKeysAndValues (d, (const void**)keys.data (), nullptr);
	std::vector<std::string> names;
	for (CFStringRef k : keys)
		names.push_back (cfText (k));
	std::sort (names.begin (), names.end ());
	std::string all;
	for (auto& n : names)
		all += " " + n;
	printf ("%s: classinfo keys:%s\n", gName, all.c_str ());
	CFDataRef data = (CFDataRef)CFDictionaryGetValue (d, kStateKey);
	if (!data || CFGetTypeID (data) != CFDataGetTypeID ())
		die ("the ClassInfo has no " + cfText (kStateKey));
	std::vector<uint8_t> out (CFDataGetBytePtr (data), CFDataGetBytePtr (data) + CFDataGetLength (data));
	CFRelease (ci);
	return out;
}

int main (int argc, char** argv)
{
	gName = "lichomat-auhost";
	if (argc != 2)
		die ("usage: lichomat-auhost PLAN");
	AuPlan a;
	const Plan p = readPlan (argv[1], [&a] (const std::string& cmd, std::istringstream& s, bool& ok) {
		if (cmd == "pull2")
		{
			uint64_t from = 0, to = 0;
			ok = !!(s >> from >> to) && from < to;
			a.pull2.push_back ({from, to});
		}
		else if (cmd == "offline")
		{
			uint64_t at = 0;
			UInt32 on = 0;
			ok = !!(s >> at >> on) && on <= 1;
			a.offline.push_back ({at, on});
		}
		else if (cmd == "ramp")
		{
			RampCmd r {};
			ok = !!(s >> r.frame >> r.id >> r.from >> r.to >> r.frames) && plug_paramIndex (r.id) >= 0 && r.frames > 0;
			a.ramps.push_back (r);
		}
		else if (cmd == "outputs")
			ok = !!(s >> a.outputs) && (a.outputs == 1 || a.outputs == 2);
		else if (cmd == "info")
			a.info = true;
		else if (cmd == "checks")
			a.checks = true;
		else
			return false;
		return true;
	});
	/* lichomat-plughost's commands of the VST3's own interfaces (plan E9.4's reviews): AU v2 has no flush, no null
	 * buffers of a bus, no edit controller; the event ring and the states from another thread or before any block are
	 * the VST3 host's checks of the processor. Not played here */
	if (!p.flushes.empty () || !p.emptyFlushes.empty () || !p.rawPoints.empty () || !p.controller.empty () || !p.events.empty ()
	    || !p.stateEarly.empty () || !p.noOutputs.empty () || p.nullOut2 || p.nullOut2Left || !p.nullOut1.empty ()
	    || !p.asyncSets.empty ())
		die ("plan: a command of lichomat-plughost alone (flush, flush-empty, param-at, controller, events, state-early, "
		     "no-outputs, null-out2, null-out2-left, null-out1, setstate-async)");
	AudioComponentDescription desc {};
	const AudioComponent comp = load (p.bundle, desc);
	using RtFn = void (*) (int);
	using RtCount = unsigned long long (*) (void);
	RtFn rtInside = p.rtcheck ? (RtFn)dlsym (RTLD_DEFAULT, "plug_rtInside") : nullptr;
	RtCount rtViolations = p.rtcheck ? (RtCount)dlsym (RTLD_DEFAULT, "plug_rtViolations") : nullptr;
	RtCount rtWrites = p.rtcheck ? (RtCount)dlsym (RTLD_DEFAULT, "plug_rtWrites") : nullptr;
	if (p.rtcheck && (!rtInside || !rtViolations || !rtWrites))
		die ("rtcheck: run with DYLD_INSERT_LIBRARIES=libplug_rtcheck.dylib");
	unsigned long long probe = 0;

## The Audio Unit

`LICHOMAT.component` is an AU v2 instrument of type `aumu`, subtype `Lcht`, manufacturer `Lchm`,
"LICHOMAT: LICHOMAT", built on Apple's AudioUnitSDK around the VST3's processor (`au/`): the same
engine per instance, the same outputs, parameters, latency and state.

- **Out 1 and Out 2** are its two output elements. AU v2 has no bus activation: Out 2 counts as
  used while the host renders it. Until then, and from two render cycles after the host stops,
  Out 1 is the sum of both outputs, as the VST3's Out 1 before Out 2 is activated. A host may also
  take one output element (Out 1 alone, always the sum).
- **Parameters** have the VST3's ids, and their values are the device's numbers: the pattern
  1-64, a pan -63..64, a voice's output St1 ... FX by name. A value the firmware changes by itself
  becomes the parameter's value at once and the host's listeners hear of it within 20 ms.
  Parameter events the host schedules (`AudioUnitScheduleParameters`) reach the firmware at their
  frames, a ramp as its two ends; a value set (`AudioUnitSetParameter`) at its offset in the next
  render, the last one of a parameter in a render winning.
- **Notes** are the host's MIDI Note Ons and Offs (`MusicDeviceMIDIEvent`) at their offsets. The AU
  declares no MIDI 2.0 protocol, so hosts send it MIDI 1.0. As for the VST3, other MIDI from the
  host (CCs, Program Changes) does not reach the firmware.
- **Sync** comes from the host callbacks: the beat and the tempo, the transport state (its second
  form if the host has it) with the cycle. A host without them gets notes but no sync.
- **State:** the AU's ClassInfo holds the VST3's state bytes (`LCHS` and `LCHV`) under the key
  `lichomat-state`, next to the keys every AU's state has.
- **Latency** is the VST3's, with the host's maximum frames per render
  (`kAudioUnitProperty_MaximumFramesPerSlice`) as the largest block. **Offline** rendering
  (`kAudioUnitProperty_OfflineRender`, Logic's bounce) waits for the engine as the VST3's offline
  mode does; the AU takes it before or after it is initialized.
- The component is not sandbox safe: it starts a process and writes `BASE`. A sandboxed host runs
  it out of its own process or not at all.

## Risks

- **No AU host and no `auval` here.** Only `lichomat-auhost` called the component. `auval` checks more than `P13_au_checks` (its own formats, element counts, render sizes and timings, many instances opened and closed), and Logic calls the AU its own way; a failure shows in the owner's install (`FAILED (auval -v aumu Lcht Lchm)`, the whole output in the log), the earlier component put back.
- **Logic's Multi-Output.** If Logic renders every output element of a Multi-Output instance from the start, Out 1 carries out 1 alone at once, as `auwrapper` did (P11 (c)). The remedy is E9.4's, for both formats: a list parameter "Out 2: separate / summed" (id 70) that decides instead of the use; small, in the processor and `plug_au.c`.
- **Logic's maximum frames per render** may be larger than its blocks (its process buffer): the AU's latency is then larger by the difference, compensated (A-14). A host that changes the maximum while initialized cannot (the SDK refuses, F4).
- **A reported value in Logic's automation.** A kit loaded with a pattern sets the AU's parameters; Logic may take the plugin's change as the user's in Touch or Latch mode, as Live may override automation (E9.4's risk); P11 (d) with Read mode.
- **Hosts that send MIDI 2.0 only, or that run AUs out of process.** The AU declares no MIDI protocol (A-17): a host that only calls `MIDIEventList()` would play no notes. A host that runs a non-sandbox-safe AU in a separate process (a sandboxed host's AU service) may forbid the engine's process; P11 uses Logic and Live, which load it in their own process.
- **The offline switch and the render thread.** A host that sets `OfflineRender` while another thread renders races the AU's new setup, as `auwrapper`'s; hosts set it between renders.
- **Restarting `AudioComponentRegistrar`.** The install does it only when `auval` does not find the new component; the agent starts again on demand, and the script refuses while a host with the plugin runs.
- **A rebuilt component with the same version.** Logic keeps its validation by component; after an update with the version unchanged (0.2.0) Logic may need "Reset & Rescan" (P11's note).
- **The first beats after an engine restart under load.** In the first replay's Release gate, at a load of 5.6–6.4 from another job, `P13_au_params_restart` found 226 loud samples after the kill with every volume 0: a beat of the new engine sounded before the host's values reached it (the first report, B-7). E9.4's review fixed that in the processor (`4db2c04`: a new engine's slave and the host's notes are held until the values it lacked have settled, F17), and the refresh's runs at `d0534b1` passed it every time. E9.4's rule holds: rerun alone; if it recurs on an idle machine, it is the processor's finding, not the AU's.
- **The VST3's cases of E9.4's reviews are not run through the AU.** `P10_plugin_null_out2`, `_silence`, `_flush_order`, `_frame_order`, `_offsets`, `_controller` test VST3 interfaces that AU v2 does not have (null bus buffers, silence flags, flushes, raw point offsets, the edit controller); `_async_state`, `_double_state`, `_early_state` and `_restart_hold` test the processor's restore generation and hold, which the AU reaches through the same `setState()`/`getState()`/`process()` calls (`P13_au_setstate`, `_params_restart`, `_vst3_state` run them through the AU). `_restart_hold` reads the MIDI from the processor's event ring (`events`, `lichomat-plughost`'s `RingTap`); a reviewer who wants it through the AU moves `RingTap` into `host_plan.h` and lets `lichomat-auhost` take `events` (a gap test of Task 5's review, not planned here).
- **The VST3's processor in C++23.** The component compiles the processor, the engine link and the card folder in C++23 (the SDK's headers need it): no warning now; an update of either SDK is checked again (both are pinned).
