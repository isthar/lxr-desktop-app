# LICHOMAT v0.8: the pattern generator (E10.3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build tracker row E10.3: the pattern generator of `docs/superpowers/specs/2026-11-11-groove-generator-design.md` (Polish, authoritative) in the LICHOMAT firmware: a pure-C core `PatternGen.c/.h` that matches the prototype `tools/gen/gen.py` byte for byte on its golden vectors, ten parameters on two new track-page sub-pages with live regeneration, `und` from the pattern's backup, the voice's `vol` switch, emulator end-to-end tests, version 0.8 and the owner's documents.

**Architecture:** `patternGen_generate()` takes the settings of one track (9 bytes), the source track (read in place) and the current track (a 554-byte copy on the stack) and rewrites the copy: 64 steps, their timing and fine nibbles, the main-step bits and the length, with the exact random generator, ranking and integer dB table of spec §5. The glue in `sequencer.c` keeps the settings per track in RAM (`seq_gen[7]`, not saved), regenerates on every parameter change while `typ` ≠ `---`, writes the copy back one step at a time with interrupts masked (as `seq_clearTrackMicro()`), touches the pattern autosave timer, and restores a track from `patternBackupBuffer` for `und`. The menu adds `PAR_GEN_*` (direct calls, as v0.6/v0.7's track page) and switches the voice's `vol` on when a generated step is below velocity 127.

**Tech Stack:** C11 (firmware: Arm GNU 14.3, `-O3 -ffast-math`; host tests: Apple clang, UBSan, ASan + UBSan; CI: GCC on Linux, strict C11), CMake 3.31, Ninja, ctest, Python 3 (`tests/pattern_gen_vectors.py` new, `render_test.py`, `emu_fuzz.py`, `drift.py`, `gen_params.py`), bash.

## Draft deviations and open points

1. **`sav` is no longer where the encoder stops** (G3). `V06_ui` (SHIFT + mode2's fifth screen), `V07_ui` (`sav`'s sign `*`; `encoder +3` → `+2`, `+13` → `+2` and `+12`), `V07_screensaver` and `V07_capture` (`encoder +13` → `+12`), and `tools/emu_fuzz.py`'s `encoder +13` change (F17). No golden changes.
2. **RAM ≈ +76 B**, not "około +70 B": `seq_gen` 63 B (+1 alignment) and `activeParameters` +10 B (+ ≤ 2 alignment).
3. **fw 1.7 plays every condition 101–115 like 100**: a generated pattern plays on LICHOMAT 0.2–0.7 as on 0.8, but on fw 1.7 its 2:2, 1:2, 4:4 and 1:4 steps play every pass. Spec §1 claims 0.7 only; the documents say it.
4. **The settings follow the track, not the pattern** (G4): after a pattern change the screens still show the track's last settings, and the next change regenerates that track in the newly shown pattern. As Euklid; the manual says it.
5. G5–G10 and G19–G21 fill gaps of the spec; G14 decides each against `gen.py`.

static uint32_t refSeed(unsigned sed, unsigned typ, unsigned sty, unsigned trk)
{
	const unsigned b[4] = { sed, typ, sty, trk };
	unsigned long long x = 2166136261ull;
	for (int i = 0; i < 4; i++)

}

/* spec §5: the places of cand (bit p, p < n) into c->order by key raw[p] x w[p], the largest
 * first, the lower place on a tie; returns how many */
static unsigned pg_rank(pg_ctx_t *c, const uint16_t *raw, const uint8_t *w, uint64_t cand, unsigned n)
{
	if (n < 64u)
		cand &= ((uint64_t)1 << n) - 1u;
	unsigned k = 0;
	while (cand)
	{
		unsigned best = 0;
		uint32_t key = 0;
		int found = 0;
		for (unsigned p = 0; p < n; p++)
		{
			const uint32_t kp = (uint32_t)raw[p] * w[p];
			if (((cand >> p) & 1u) && (!found || (kp > key)))
			{
				best = p;
				key = kp;
				found = 1;
			}
		}
		c->order[k++] = (uint8_t)best;
		cand &= ~((uint64_t)1 << best);
	}
	return k;
}

static int pg_isOn(const uint16_t *on, unsigned s) { return (on[s >> 4] >> (s & 15u)) & 1u; }

}

	}

}

/* spec §4.1 (G6, G9): accents, den ghosts by rank, var's extra or 1:2 ghosts; 4 bars alike */
static void pg_hat(pg_ctx_t *c, const PatternGenSettings *s, PatternGenTrack *io)
{
	/* the ghost weight of a quarter, an offbeat and a 2nd or 4th 16th, styles 0-4 */
	static const uint8_t wq[5] = { 2, 2, 0, 8, 1 }, wo[5] = { 1, 0, 0, 0, 1 }, we[5] = { 4, 4, 4, 3, 1 };
	uint16_t acc = (c->sty == 2u) ? 0x5555u : 0x4444u;	/* the offbeats; style 2 the quarters too */
	if (c->sty == 0u)
	{
		acc = 0;
		for (unsigned p = 0; p < 16u; p++)
			if (pg_isOn(io->on, p) && ((io->step[p].volume & 0x7Fu) >= PG_ACCENT_MIN))
				acc |= (uint16_t)(1u << p);
	}
	uint8_t w[16];
	uint64_t cand = 0;
	for (unsigned p = 0; p < 16u; p++)
	{
		const unsigned q = p & 3u;
		w[p] = ((acc >> p) & 1u) ? 0 : (q == 0u) ? wq[c->sty] : (q == 2u) ? wo[c->sty] : we[c->sty];
		if (w[p])
			cand |= (uint64_t)1 << p;
	}
	const unsigned nfree = pg_rank(c, c->raw, w, cand, 16);
	const unsigned den = ((unsigned)s->den < nfree) ? (unsigned)s->den : nfree;
	const unsigned more = (s->var > 0) ? (unsigned)s->var : 0u, fewer = (s->var < 0) ? (unsigned)-s->var : 0u;
	const unsigned plus = (more < nfree - den) ? more : nfree - den, minus = (fewer < den) ? fewer : den;
	uint8_t prob[16] = { 0 };
	for (unsigned i = 0; i < den + plus; i++)
		prob[c->order[i]] = (i >= den) ? PG_COND_2_2 : (i + minus >= den) ? PG_COND_1_2 : PG_PROB_ALWAYS;
	memset(io->on, 0, sizeof io->on);
	for (unsigned st = 0; st < PG_STEPS; st++)
	{
		const unsigned p = st & 15u;
		if (((acc >> p) & 1u) && (c->sty == 0u))
			pg_copy(io, st, p);
		else if ((acc >> p) & 1u)
			pg_put(c, io, st, 127, PG_PROB_ALWAYS, c->note);
		else if (prob[p])
			pg_put(c, io, st, patternGen_dbVel(s->lev + c->off[p]), prob[p], c->note);
	}
}

uint8_t patternGen_generate(const PatternGenSettings *in, uint8_t track, const PatternGenSource *src, PatternGenTrack *io)
{
	if (!in || !io || (track >= PG_TRACKS))
		return 0;
	const PatternGenSettings s = patternGen_checked(*in);
	if ((s.typ == PG_TYPE_OFF) || ((s.typ == PG_TYPE_PRP) && ((s.src == track) || !src)))
		return 0;	/* spec §4.5: prp without a source does nothing */
	pg_ctx_t c;
	memset(&c, 0, sizeof c);
	c.x = patternGen_seed(&s, track);
	const unsigned n = (s.typ == PG_TYPE_PRC) ? 32u : 16u;
	for (unsigned p = 0; p < n; p++)	/* draw 1: the keys (spec §5) */
		c.raw[p] = (uint16_t)pg_rand(&c, 65536u);
	for (unsigned p = 0; p < n; p++)	/* draw 2: the level offsets (G10) */
		c.off[p] = (int8_t)((s.typ == PG_TYPE_PRC) ? (int)pg_rand(&c, 5u) - 2 : (int)pg_rand(&c, 6u) - 3);
	c.kick = pg_kick(&s, track, src);
	c.note = pg_noteOf(PG_NOTE_BASE + s.note);
	c.sty = ((s.sty < pg_styMin[s.typ]) || (s.sty > pg_styMax[s.typ])) ? 1u : s.sty;
	switch (s.typ)
	{
	case PG_TYPE_HAT:	pg_hat(&c, &s, io); break;
	default:		return 0;	/* Task 3: sub prc rar prp */
	}
	io->length = PG_STEPS;
	return (uint8_t)(PG_WROTE | c.soft);
}

/* spec §4.2: the bar of styles 1-7 (bit p is step p + 1), style 7's second bar; style 8's quarter
 * figures ...x ..xx .xxx ..x. .... and their weights (G10) */
static const uint16_t pg_subBar[8] = { 0, 0x8888u, 0xCCCCu, 0xEEEEu, 0x4444u, 0x4C4Cu, 0x40C0u, 0x0CCCu };
#define PG_SUB_BAR_B	0xECCCu
static const uint8_t pg_subFig[5] = { 0x8, 0xC, 0xE, 0x4, 0x0 }, pg_subFigW[5] = { 3, 4, 1, 2, 1 };

/* spec §4.2: off the kick; the last hit before a kick at 127, the others at lev; var's second
 * note on beats 2 and 4; style 8's den caps the hits a bar by key (G8) */
static void pg_sub(pg_ctx_t *c, const PatternGenSettings *s, PatternGenTrack *io)
{
	uint16_t bar[2];
	if (c->sty == 8u)
	{
		uint16_t h = 0;
		for (unsigned q = 0; q < 4u; q++)	/* draw 3: one figure per quarter */
		{
			unsigned r = pg_rand(c, 11u), f = 0;
			while (r >= pg_subFigW[f])
				r -= pg_subFigW[f++];
			h |= (uint16_t)(pg_subFig[f] << (4u * q));
		}
		h &= (uint16_t)~c->kick;
		if (s->den)
		{
			uint8_t one[16];
			memset(one, 1, sizeof one);
			const unsigned m = pg_rank(c, c->raw, one, h, 16);
			for (unsigned i = s->den; i < m; i++)
				h &= (uint16_t)~(1u << c->order[i]);
		}
		bar[0] = bar[1] = h;
	}
	else
	{
		bar[0] = (uint16_t)(pg_subBar[c->sty] & ~c->kick);
		bar[1] = (uint16_t)(((c->sty == 7u) ? PG_SUB_BAR_B : pg_subBar[c->sty]) & ~c->kick);
	}
	memset(io->on, 0, sizeof io->on);
	for (unsigned st = 0; st < PG_STEPS; st++)
	{
		const uint16_t h = bar[(st >> 4) & 1u];
		const unsigned p = st & 15u;
		unsigned last = 0;
		if (!((h >> p) & 1u))
			continue;
		for (unsigned d = 1; (d < 16u) && !((h >> ((p + d) & 15u)) & 1u); d++)	/* up to the next hit */
			if ((c->kick >> ((p + d) & 15u)) & 1u)
				last = 1;
		const int second = (s->var != 0) && ((p & 4u) != 0u);	/* steps 5-8 and 13-16 */
		pg_put(c, io, st, last ? 127 : patternGen_dbVel(s->lev), PG_PROB_ALWAYS,
			pg_noteOf(PG_NOTE_BASE + s->note + (second ? s->var : 0)));
	}
}

/* spec §4.3 (G6, G8, G9): bar 1's accents by rank, bar 2 one moved (draw 3), ghosts just before
 * accents, bars 3-4 as 1-2 with var's changes in bar 4 */
static void pg_prc(pg_ctx_t *c, const PatternGenSettings *s, PatternGenTrack *io)
{
	static const uint8_t wq[3][4] = { { 1, 1, 1, 1 }, { 0, 4, 2, 4 }, { 0, 2, 6, 2 } };	/* by the 16th of the quarter */
	static const uint16_t wp3 = (1u << 3) | (1u << 6) | (1u << 11) | (1u << 14);	/* style 3's places 4 7 12 15 */
	uint8_t w[16], wv[16], rank[2][16];
	unsigned n[2];
	uint16_t acc[2] = { 0, 0 }, ghost[2] = { 0, 0 }, plus = 0, minus = 0;
	uint64_t cand = 0, own[2] = { 0, 0 }, free2;
	for (unsigned st = 0; st < 32u; st++)	/* the own accents of bars 1 and 2 (G6) */
		if (pg_isOn(io->on, st) && ((io->step[st].volume & 0x7Fu) >= PG_ACCENT_MIN))
			own[st >> 4] |= (uint64_t)1 << (st & 15u);
	for (unsigned p = 0; p < 16u; p++)
	{
		w[p] = (c->sty <= 2u) ? wq[c->sty][p & 3u] : (c->sty == 3u) ? (((wp3 >> p) & 1u) ? 8 : 1) : 1;
		wv[p] = (p >= 12u) ? 4 : 1;
		cand |= (uint64_t)(w[p] && !((c->kick >> p) & 1u)) << p;
	}
	for (unsigned b = 0; b < 2u; b++)	/* style 0: each bar's own accents by its keys; else bar 1's by rank */
	{
		n[b] = pg_rank(c, &c->raw[(c->sty == 0u) ? 16u * b : 0u], w, (c->sty == 0u) ? own[b] : cand, 16);
		if ((c->sty != 0u) && (n[b] > (unsigned)s->den))
			n[b] = s->den;
		memcpy(rank[b], c->order, n[b]);
	}
	free2 = cand;
	for (unsigned i = 0; i < n[0]; i++)
		free2 &= ~((uint64_t)1 << rank[0][i]);
	if ((c->sty != 0u) && n[0] && free2)	/* draw 3: bar 2 moves one accent to bar 2's best free place */
	{
		const unsigned i = pg_rand(c, n[0]);
		(void)pg_rank(c, &c->raw[16], w, free2, 16);
		rank[1][i] = c->order[0];
	}
	for (unsigned b = 0; b < 2u; b++)
		for (unsigned i = 0; i < n[b]; i++)
			acc[b] |= (uint16_t)(1u << rank[b][i]);
	const unsigned g = (((unsigned)s->den + 1u) / 2u < 3u) ? ((unsigned)s->den + 1u) / 2u : 3u;
	for (unsigned b = 0; b < 2u; b++)
		for (unsigned i = 0, k = 0; (i < n[b]) && (k < g); i++)
		{
			const uint16_t bit = (uint16_t)(1u << ((rank[b][i] + 15u) & 15u));	/* the step before, in its bar */
			const unsigned isFree = !((acc[b] | ghost[b] | c->kick) & bit);
			ghost[b] |= (uint16_t)(isFree ? bit : 0u);
			k += isFree;
		}
	if (s->var > 0)
	{
		const uint64_t free4 = 0xFFFFu & ~(uint64_t)(acc[1] | ghost[1] | c->kick);
		const unsigned m = pg_rank(c, &c->raw[16], wv, free4, 16);
		for (unsigned i = 0; (i < (unsigned)s->var) && (i < m); i++)
			plus |= (uint16_t)(1u << c->order[i]);
	}
	else
		for (unsigned i = 0; (i < (unsigned)-s->var) && (i < n[1]); i++)
			minus |= (uint16_t)(1u << rank[1][n[1] - 1u - i]);
	memset(io->on, 0, sizeof io->on);
	for (unsigned st = 0; st < PG_STEPS; st++)
	{
		const unsigned h = (st >> 4) & 1u, p = st & 15u, bar4 = (st >= 48u);
		const uint16_t bit = (uint16_t)(1u << p);
		const uint8_t prob = (bar4 && (minus & bit)) ? PG_COND_1_2 : PG_PROB_ALWAYS;
		if ((acc[h] & bit) && (c->sty == 0u))
		{
			pg_copy(io, st, 16u * h + p);
			if (prob != PG_PROB_ALWAYS)
				io->step[st].prob = (uint8_t)((io->step[st].prob & STEP_SLIDE_FLAG) | prob);
		}
		else if (acc[h] & bit)
			pg_put(c, io, st, 127, prob, c->note);
		else if (ghost[h] & bit)
			pg_put(c, io, st, patternGen_dbVel(s->lev + c->off[16u * h + p]), PG_PROB_ALWAYS, c->note);
		else if (bar4 && (plus & bit))
			pg_put(c, io, st, 127, PG_COND_2_2, c->note);
	}
}

/* spec §4.4 style 3: m of the 64 steps by a key each (draw 3), bars 1 and 4 weigh 2, off the
 * kick and skip, at 25 % (G10) */
static void pg_rarScatter(pg_ctx_t *c, PatternGenTrack *io, unsigned m, uint64_t skip)
{
	uint8_t w[PG_STEPS];
	uint64_t cand = 0;
	for (unsigned st = 0; st < PG_STEPS; st++)
	{
		c->raw[st] = (uint16_t)pg_rand(c, 65536u);
		w[st] = ((st < 16u) || (st >= 48u)) ? 2 : 1;
		if (!((c->kick >> (st & 15u)) & 1u) && !((skip >> st) & 1u))
			cand |= (uint64_t)1 << st;
	}
	const unsigned n = pg_rank(c, c->raw, w, cand, PG_STEPS);
	for (unsigned i = 0; (i < m) && (i < n); i++)
		pg_put(c, io, c->order[i], 127, PG_PROB_RARE, c->note);
}

/* spec §4.4 (G19): everything at 127 */
static void pg_rar(pg_ctx_t *c, const PatternGenSettings *s, PatternGenTrack *io)
{
	const unsigned den = s->den;
	memset(io->on, 0, sizeof io->on);
	switch (c->sty)
	{
	case 2:
		if (den)
			pg_put(c, io, 0, 127, (den == 1u) ? PG_COND_1_4 : (den <= 3u) ? PG_COND_1_2 : PG_PROB_ALWAYS, c->note);
		break;
	case 3:
		pg_rarScatter(c, io, (den < 8u) ? den : 8u, 0);
		break;
	case 4:
		pg_put(c, io, 0, 127, PG_COND_1_2, c->note);
		pg_put(c, io, 48, 127, PG_COND_4_4, c->note);
		pg_rarScatter(c, io, (den > 2u) ? (((den - 2u) < 8u) ? den - 2u : 8u) : 0u, ((uint64_t)1 << 0) | ((uint64_t)1 << 48));
		break;
	default:	/* 1 */
		if (den)
			pg_put(c, io, 48, 127, (den >= 2u) ? PG_COND_2_2 : PG_COND_4_4, c->note);
		for (unsigned st = 56; (den >= 3u) && (st < 60u); st++)
		{
			pg_put(c, io, st, 127, (den >= 4u) ? PG_COND_2_2 : PG_COND_4_4, c->note);
			io->timing[st].flam = PG_FLAM_X4;
		}
		break;
	}
}

/* spec §4.5 (G21): the source repeated to 64 steps; copy, fill, pickups, echo */
static void pg_prp(pg_ctx_t *c, const PatternGenSettings *s, const PatternGenSource *src, PatternGenTrack *io)
{
	static const uint8_t wq[4] = { 1, 4, 3, 4 };	/* style 2: quarter, 2nd, offbeat, 4th */
	const unsigned len = (src->length == 0) ? 16u : (src->length > PG_STEPS) ? PG_STEPS : src->length;
	const unsigned shf = (unsigned)(s->shf + PG_STEPS);

			on |= (uint64_t)1 << st;
			if ((src->step[st % len].volume & 0x7Fu) >= PG_ACCENT_MIN)
				accent |= (uint64_t)1 << st;

	{
		const unsigned m = pg_rank(c, c->raw, w, (~on >> (16u * b)) & 0xFFFFu, 16);
		for (unsigned i = 0; (i < (unsigned)s->den) && (i < m); i++)
			pg_put(c, io, 16u * b + c->order[i], 127, PG_PROB_ALWAYS, c->note);
	}
	for (unsigned st = 0; (c->sty != 2u) && (st < PG_STEPS); st++)
	{
		const unsigned before = (st + PG_STEPS - 1u) % PG_STEPS, later = (st + shf) % PG_STEPS;
		if ((c->sty == 3u) && ((accent >> st) & 1u) && !((on >> before) & 1u))
			pg_put(c, io, before, patternGen_dbVel(s->lev + c->off[before & 15u]), PG_PROB_ALWAYS, c->note);

				pg_noteOf((int)(x->note & 0x7Fu) + s->note));
		}
	}
}
